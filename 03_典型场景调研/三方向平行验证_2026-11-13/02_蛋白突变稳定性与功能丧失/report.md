# 蛋白突变稳定性与功能丧失调研报告（严格提示词复核版）

## 最终判断

**失败，不建议作为当前大创申报书的主场景。**

该方向拥有三者中最成熟的公开benchmark，但在新定义下没有抽到数据库外的样本级非结构化阴性数据。5篇ProteinGym相关开放全文的严格有效证据块为0。旧报告的12条主要来自Figure、补充图、明确数值结果、高通量突变矩阵或assay局限讨论，不能再计作正文新增样本。

## 1. 任务与公开benchmark

ProteinGym为蛋白突变效应预测提供公开DMS数据、统一方向的`DMS_score`、二值标签、标准划分和评价指标。它能够直接评价序列到突变效应的预测，是成熟的第三方benchmark。

| 条件 | 结果 |
|---|---|
| 明确输入输出 | 有：蛋白序列/突变到DMS效应 |
| 公开标准答案 | 有：DMS矩阵与统一标签 |
| 公开评价指标 | 有：Spearman、AUC、MCC、MSE等 |
| 无需自建基础benchmark | 是 |

该方向的问题不在benchmark，而在**正文中剩余的数据库外样本级增量几乎为零**。高通量研究通常已把逐突变结果存入矩阵、补充数据或公共数据库；正文只挑选少量代表突变进行解释。

## 3. 为什么`p.Trp409Ter`也不计入

PMC6993387正文写到`p.Trp409Ter`未被互补实验识别为有害。这句话表面上满足“自然语言＋阴性结果”，但其底层结果来自论文已经构建的变体功能图谱；正文是在指出图谱的假阴性和成熟cDNA互补assay无法反映NMD的边界。

因此它是有价值的**方法学审计信息**，但不是数据库外新增的突变样本。若把它计入，仍然是在把已经结构化的结果换一种自然语言表达，与当前项目要补充训练数据的目标不符。

## 4. 质量与模型价值判断

本轮没有可进入核心数据集的记录，因而不能计算有效证据的质量分布。被排除的信息仍有两类用途：

- 可作为抽取系统的负例，训练系统识别Figure复述、数值结果和方法学讨论；
- 可作为模型错误分析的背景，解释某些benchmark标签为什么受assay机制限制。

但它们不能作为新增训练样本去证明“加入非结构化阴性数据可提升ProteinGym成绩”。在5篇样本中没有发现既未结构化、又能映射到同一突变效应任务的新增标签。

## 5. 对旧报告的纠正

旧报告的“12条A+B、5/5篇命中、成功”结论依赖较宽口径：只要正文提供条件、机制或assay边界就计数。新提示词要求结果本身未被Figure/Table/entry/结构化实验记录收录，且不能是明确数值结果复述。按这个条件，旧12条全部被排除。

这不是说突变效应研究没有阴性数据，而是说**这些阴性数据通常已经高度结构化**，不符合本项目“从自然语言补充数据库缺失训练数据”的典型场景要求。
