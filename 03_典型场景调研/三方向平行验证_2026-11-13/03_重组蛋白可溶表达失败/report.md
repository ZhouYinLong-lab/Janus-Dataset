# 重组蛋白可溶表达失败调研报告（严格提示词复核版）

## 最终判断

**失败，不建议作为当前大创申报书的主场景。**

该方向有成熟的可溶表达benchmark，但5篇开放全文中仅1篇留下1个严格有效证据块：对pET-xynA2重组细胞进行升温处理未能提高XynA可溶产量，且原文明确标注“data not shown”。其余旧记录主要来自Figure、Table、补充文件或明确数值结果。

## 1. 任务与公开benchmark

| 资源 | 任务 | 是否可直接复用 |
|---|---|---|
| NESG | 蛋白序列到表达/可溶回收等级 | 是 |
| SoluProt | E. coli可溶表达二分类 | 是 |
| eSOL | E. coli蛋白定量溶解度 | 是，但实验体系不同 |

因此，本方向具有外部benchmark。问题仍然是正文独有的实验失败信息太少，而且抽到的温度、菌株、标签、构建体等条件未必能与以序列为主的benchmark输入直接对齐。

## 3. 有效证据质量

唯一保留记录同时具备：

- 实验对象：pET-xynA2表达的成熟XynA；
- 干预条件：对重组细胞进行温度上调；
- 评价终点：可溶产量；
- 阴性结论：未能改善；
- 非结构化依据：原文标注data not shown，未给出明确结果数值。

因此该条质量较高，适合作为抽取示例。但单条高质量数据不能证明领域层面数据充足。

## 4. 对旧10条结论的纠正

旧报告把Figure/Table中已经展示的表达成败，只要正文补充了构建体、菌株、标签或机制，就计作A/B证据。新提示词要求阴性结果本身没有被结构化记录，故这些条目必须排除。旧“10条、5/5篇命中、成功”的结论废止。

严格结果为1块、1/5篇命中。即使定向扩展文献，当前样本也没有证据支持旧报告提出的“约1条/篇”规模假设。

## 5. 模型验证问题

NESG、SoluProt和NetSolP主要以蛋白序列为输入，并在相对固定的表达流程中给出结果。正文独有记录往往描述温度、菌株、标签、诱导方式和构建体变化。若benchmark不提供这些条件字段，模型无法在同一测试集上判断“升温是否能救援某个构建体”。

可以把文本阴性作为额外训练样本加入基础可溶性模型，但1条样本没有训练意义；即使未来增加数量，也必须先证明这些记录可映射到benchmark的序列和标签定义，且不会因条件差异制造标签冲突。

## 6. 最终判定

| 条件 | 要求 | 结果 | 是否通过 |
|---|---:|---:|---|
| 外部benchmark | 有 | NESG/SoluProt等 | 是 |
| 5篇命中文献 | ≥3篇 | 1篇 | 否 |
| 有效证据块 | ≥5块 | 1块 | 否 |
| 条件增量可被benchmark评价 | 可直接承接 | 尚不能 | 否 |

**结论标签：严格验证失败。** 有一条高质量示例，但数量不足且条件字段与benchmark不完全对齐；仅适合作为迁移案例。
