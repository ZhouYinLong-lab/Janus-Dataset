# 典型场景复核报告：转氨酶-底物相容性预测与酶选择

**对应项目方向：** 生化领域科学文献中非结构化阴性数据挖掘及其驱动的模型优化方法研究  
**复核日期：** 2026-11-13  
**复核目标：** 同时验证该场景是否具有公开 benchmark，以及文献中是否存在数量较多、能够形成模型样本且尚未被目标数据库充分收录的真实阴性数据。

## 一、复核结论

本次复核支持将下列任务作为大创项目的典型应用场景：

> **以合成生物催化中的转氨酶-底物相容性预测与酶选择为例，从论文正文、图表和补充材料中抽取“已测试但无转化、无可检测活性或低于实用转化阈值”的条件性阴性结果，形成真实负例数据，并验证其对活性预测、候选酶排序和模型假阳性控制的作用。**

该场景通过了两项核心门槛：

1. **有可复现的公开 benchmark。** 已有25种转氨酶乘18种底物的450对完整筛选矩阵；另有2026年公开的528条转氨酶筛选及独立验证数据，可直接开展转化率预测和酶选择。
2. **阴性数据密度高且存在数据库外增量。** 两套公开矩阵中分别有264条二分类阴性记录，以及120条零转化、242条低于25%实用阈值的记录。RetroBioCat目前仅完成41/141篇转氨酶论文的数据录入；对未录入开放全文的抽样检查进一步确认，多篇论文含可落成“酶/变体-底物-条件-结果”的真实阴性记录。

因此，本场景不是“只有 benchmark、没有可挖掘增量”，也不是“论文只是把数据库结果换成自然语言”。更准确的判断是：**已有结构化数据可作为基准和金标准，同时仍有一批未完成结构化的条件性阴性结果可供挖掘。**

综合判断：**推荐作为主场景，置信度中高。** 但申报书不应声称“现有数据库没有阴性数据”或“文献中存在海量全新负例”；项目创新点应表述为“对未充分录入、带实验条件的真实阴性结果进行规模化识别、标准化和增量验证”。

## 二、核验标准

一个场景只有同时满足以下条件，才适合本项目：

| 核验维度 | 通过标准 |
|---|---|
| 公开 benchmark | 有公开数据、明确任务和可复现标签，可作为模型基线 |
| 阴性数据密度 | 真实筛选矩阵中存在较高比例的无活性、零转化或低转化结果 |
| 文献增量 | 目标数据库存在未完成录入的论文，且原文中确有可结构化阴性记录 |
| 样本可用性 | 能识别酶或变体、底物、实验条件、检测方法和阴性结局 |
| 模型相关性 | 阴性结果能够直接作为相容性分类、转化率预测或酶排序的监督信号 |
| 可验证性 | 可比较“benchmark/数据库数据”与“加入文献真实负例”后的模型表现 |

特别需要区分三类信息：

- **有效阴性：** 明确做过实验，结果为无转化、无可检测活性或低于预设阈值。
- **无效伪阴性：** 未报道、未测试、实验失败、酶未表达或底物未加入。
- **与任务无关的否定描述：** 稳定性下降、阴性对照、没有统计学差异等，不能直接作为酶-底物相容性标签。

## 三、公开 benchmark 核验

### 3.1 Aminotransferase benchmark

Goldman/Coley公开的 enzyme-datasets 仓库提供了转氨酶回归和二分类数据，来源为Li等人的系统筛选研究。数据构成为：

- 25种转氨酶；
- 18种底物；
- 25乘18等于450个完整酶-底物组合；
- 同时提供连续活性和二分类版本。

本次直接读取公开的 `aminotransferase_binary.csv` 后统计得到：

| 类别 | 记录数 | 比例 |
|---|---:|---:|
| 阳性 | 186 | 41.3% |
| 阴性 | 264 | 58.7% |
| 合计 | 450 | 100% |

这说明转氨酶底物谱不是“几乎全为阳性”的任务。阴性结果在统一实验条件下占多数，可直接用于建立和评估相容性分类模型。

数据与说明：<https://github.com/samgoldman97/enzyme-datasets>

### 3.2 2026年转氨酶选择数据集

Raghavan等人在2026年发表并公开了面向转氨酶选择的机器学习流程，包含：

- 初始筛选：8种商业转氨酶乘42种酮，共336条反应；
- 独立验证：8种转氨酶乘24种环状酮，共192条反应；
- 合计528条反应记录；
- 下游任务包括转化率预测、是否达到实用转化阈值以及候选酶排序。

本次直接读取作者公开CSV后得到：

| 数据部分 | 总记录 | 零转化 | 低于25%转化阈值 | 不低于25% |
|---|---:|---:|---:|---:|
| 初始筛选 | 336 | 49 | 143 | 193 |
| 独立验证 | 192 | 71 | 99 | 93 |
| 合计 | 528 | 120 | 242 | 286 |

零转化记录占22.7%，低于25%实用阈值的记录占45.8%。论文还将“对某底物所有候选酶均无法提供实用转化”作为需要模型识别的实际失败情形。因此，阴性数据不仅数量充足，而且与“为新底物选择合适的酶”这一真实应用直接对应。

论文：<https://doi.org/10.1039/d6sc00852f>  
数据与代码：<https://github.com/priyanka-rag/transaminase_external>

### 3.3 benchmark 核验结论

| 问题 | 结论 |
|---|---|
| 是否有公开 benchmark | 有，而且至少有两套相互独立的数据来源 |
| 是否包含真实阴性 | 有，且阴性比例较高 |
| 是否支持模型对比 | 支持二分类、回归和酶排序 |
| 是否能做严格外部验证 | 可以使用独立底物集、按底物骨架划分或按酶划分 |

**第一道门槛明确通过。**

## 四、文献中是否存在较多“有用阴性数据”

### 4.1 RetroBioCat覆盖现状

RetroBioCat是当前与合成生物催化最相关的人工整理数据库之一。其转氨酶页面在复核时显示：

- 141篇候选论文；
- 仅41篇完成数据录入，完成率29%；
- 269条酶记录，其中237条具有蛋白质序列；
- 1,443条活性记录；
- 已录入记录中65%为active，34%为inactive，约491条阴性记录。

这些数字同时说明两件事：

1. 阴性结果在转氨酶文献中不是偶发现象，已有人工整理数据中约三分之一为inactive；
2. 该数据库并未完成对候选论文的录入，仍存在明确的待整理文献池。

来源：<https://retrobiocat.com/enzyme_homepage/TA>

### 4.2 对未录入论文池的抽样核验

本次进一步解析RetroBioCat的转氨酶论文列表，而不是仅依据完成率推断。结果如下：

| 指标 | 数量 |
|---|---:|
| 候选论文总数 | 141 |
| 标为Complete | 41 |
| Data required | 92 |
| 其它未完成状态 | 8 |
| 当前activity记录数为0的论文 | 98 |

在activity记录为0的论文中，通过DOI与Europe PMC匹配获得27篇开放全文；去除1篇虽无activity记录但状态为Complete的论文后，形成26篇严格意义上的未完成录入开放论文候选集。自动全文抓取成功24篇，其中15篇命中“no conversion”“no detectable activity”“not accepted”“not detected”“low conversion”等阴性表达。

由于关键词命中并不等于有效样本，本次又进行人工语义复核，排除以下情况：

- 只描述酶稳定性或固定化效果；
- 阴性对照或无酶对照；
- “未检测”实际指底物或产物回收失败；
- 没有明确酶-底物对应关系；
- 没有实际进行反应测试。

保守复核后，至少7篇论文明确包含可落成任务样本的阴性数据。这个数字是“已人工确认有用论文数”，不是把15篇关键词命中文献全部算成有效，也没有把尚未人工展开的图表条目夸大计数。

### 4.3 代表性增量证据

| 论文 | 已确认的阴性信息 | 为什么可用于建模 | 数据库状态核对 |
|---|---|---|---|
| Computational Redesign of an omega-Transaminase | 野生型对6种大体积目标胺无可检测活性；40个不同设计中另有2个未成功的变体-底物组合 | 酶/变体、目标底物和活性结果明确，至少形成8条真实负例 | RetroBioCat列表中为Data required，activity为0 |
| Genome mining and characterisation of a novel transaminase | 图中以“-”明确表示no conversion，并区分0-10%、10-30%和大于30%转化 | 可建立二分类或有序多分类标签；图注明确了阈值和重复实验 | 数据录入尚未完成，activity为0 |
| Amination of omega-functionalized aliphatic primary alcohols | 表格以n.c.表示no conversion，并指出若干底物类别未发生转化 | 可恢复底物、反应体系和条件性无转化结果 | 位于未完成录入候选池 |

### 4.4 “较多”的合理解释

现有证据支持以下结论：

- **在完整筛选矩阵中，阴性记录数量确实很多。** 两个公开数据源合计已有384条零值/二分类阴性；若按25%实用阈值，2026年数据 alone 有242条低转化记录。
- **在数据库未完成录入的论文中，确实能够找到有效增量。** 本次开放全文小样本中，至少7/24篇经过人工复核后含任务相关阴性数据。
- **单篇论文往往包含多个负例。** 例如一篇设计研究至少形成8条明确负例，底物谱图和筛选矩阵通常还会产生多条酶-底物记录。

但现阶段尚不能严谨声称“未录入论文中已经精确发现数百条全新负例”，因为部分记录仍位于图像或补充材料中，需要逐项识别、实体对齐和去重。这一工作本身正适合作为大创项目的研究内容。

**第二道门槛通过，证据强度足以支持项目申报，但应保持上述边界。**

## 五、为什么这些阴性数据能产生数据库以外的增量

本项目需要的不是简单抽取“作者说反应失败”，而是形成以下条件化记录：

`论文ID + 酶/变体 + 底物结构 + 反应方向 + pH + 温度 + 时间 + 辅因子/供体 + 检测方法 + 转化结果/阈值 + 证据位置`

其增量主要来自：

1. **测试失败的组合。** 通用反应数据库通常优先记录已发生的反应，未发生反应不构成标准反应式，因而容易缺失。
2. **条件性标签。** 同一酶-底物对在不同pH、温度、供体或溶剂条件下可能有不同结局，简单active/inactive标签无法完整表示。
3. **变体与底物的细粒度配对。** 蛋白工程论文常以图表展示大量变体筛选结果，数据库未必逐条录入。
4. **检测限和低转化阈值。** “未检测到”“小于1%”“小于25%”具有不同含义，可支持不同模型任务。
5. **困难负例。** 实验者通常测试的是在结构或功能上看似可能成功的候选底物，这些真实负例比随机拼接酶与无关分子更能约束模型。

因此，项目的目标应是提取**数据库未充分结构化的实验事实和条件信息**，而不是把数据库已有的inactive标签改写成自然语言。

## 六、与其它候选场景的对比

| 比较维度 | 转氨酶-底物相容性 | 蛋白互作突变亲和力下降 | 重组蛋白表达/纯化失败 |
|---|---|---|---|
| 公开 benchmark | 有，两套可直接使用 | 有SKEMPI等成熟数据库 | 有TargetTrack、NESG、eSOL等 |
| benchmark内阴性密度 | 高，完整筛选中约46%-59%为低转化/阴性 | 较高，但大量记录已结构化 | 高，但任务和流程标签较复杂 |
| 数据库外文献增量 | 中高，存在大量未完成录入的底物谱和变体筛选论文 | 较低，很多典型实验已进入专业数据库 | 中，需处理表达系统和流程阶段差异 |
| 阴性与模型目标的直接性 | 高，无转化/低转化就是目标标签 | 高，亲和力变化可直接建模 | 中，失败可能来自多个环节 |
| 条件标准化难度 | 中，可围绕反应条件建模 | 中，测量方法和条件仍需对齐 | 高，宿主、载体、纯化流程差异大 |
| 申报书叙事完整性 | **强：抽取-标准化-去重-模型优化闭环清晰** | 中：容易被质疑只是重建SKEMPI | 中：与生化反应预测的联系较弱 |
| 推荐结论 | **主场景** | 抽取准确性对照或扩展任务 | 扩展场景 |

## 七、建议的项目验证设计

### 7.1 数据抽取验证

1. 以RetroBioCat未完成录入的转氨酶论文为主要文献池；
2. 优先处理开放获取且含表格、底物谱图或补充表的论文；
3. 采用两名成员独立标注，计算字段级准确率和一致性；
4. 每条记录保存原文、图表编号和补充材料页码，保证可追溯；
5. 以DOI、酶序列/UniProt、底物InChIKey、反应条件进行去重；
6. 分别报告“抽取总量”“可用记录数”“数据库新增数”和“条件更完整数”。

### 7.2 模型增益验证

设置以下对比：

- 基线A：公开benchmark中的正例加随机负例；
- 基线B：公开benchmark原始真实阴性；
- 实验组：benchmark加文献挖掘并去重后的真实阴性；
- 消融组：去除反应条件，只使用酶序列和底物结构。

数据划分不能只使用随机划分，应至少包含：

- 未见底物骨架划分；
- 未见酶或低同源酶划分；
- 按论文来源划分，防止同一筛选矩阵泄漏到训练集和测试集。

主要指标建议包括AUPRC、MCC、F1、校准误差，以及结构相似困难负例上的假阳性率。只有当加入文献真实阴性后，在严格划分下仍能降低假阳性或改善酶排序，才能证明“阴性数据驱动的模型优化”成立。

## 八、可直接用于申报书项目简介的段落

本项目拟以**合成生物催化中的转氨酶-底物相容性预测与酶选择**为典型应用场景。现有酶学与反应数据库主要收录已知功能及成功反应，而大量“某转氨酶或其变体在特定条件下对候选底物无转化、无可检测活性或低于实用转化阈值”的实验结果仍分散于论文正文、图表及补充材料中，尚未被充分结构化。公开筛选数据表明，此类阴性结果在转氨酶底物谱中占有较高比例，并直接影响模型对新底物的候选酶选择和假阳性控制。项目将研究面向酶、底物、反应条件和实验结局的非结构化阴性证据识别、实体对齐、条件化表示与可信度判定方法，构建经数据库去重和人工复核的真实阴性数据集，并通过与随机负例及现有benchmark的对比，验证文献阴性数据对相容性预测、转化能力判断和候选酶排序的提升作用。在此基础上，进一步将所形成的通用方法框架拓展至氧化酶、腈水解酶等其它生物催化任务，以及突变体失活、蛋白表达失败等相关生化问题。

## 九、风险与申报书表述边界

| 风险 | 控制办法 |
|---|---|
| 把未报道当成阴性 | 只接受明确说明已测试且无活性、无转化或低于阈值的记录 |
| 否定词命中但语义无关 | 增加酶-底物关系、实验动作和检测结果联合判定，并人工复核 |
| 数据库重复 | 与RetroBioCat及公开benchmark进行实体级和条件级去重 |
| 条件不一致导致标签冲突 | 阴性标签必须绑定pH、温度、时间、供体、溶剂和检测方法 |
| 模型提升来自数据泄漏 | 按论文、酶同源性和底物骨架严格划分训练与测试集 |
| 论文图像难以自动解析 | 首期优先处理可恢复名称/编号的表格，并保留人工校对环节 |

申报书中应避免以下表述：

- “现有数据库完全没有转氨酶阴性数据”；
- “已经发现数百条数据库外阴性数据”；
- “加入阴性数据必然提高模型性能”；
- “某酶与某底物在所有条件下绝对不相容”。

更稳妥的表述是：**已有数据库证明阴性结果具有较高密度，但论文录入尚不完整；本项目将挖掘未充分结构化的条件性真实负例，并通过严格的增量和模型实验验证其价值。**

## 十、最终判断

| 最终问题 | 判断 |
|---|---|
| 有公开benchmark吗 | **有** |
| benchmark中阴性数据多吗 | **多，约46%-59%为低转化或阴性** |
| 文献中还有数据库外增量吗 | **有，已通过未录入论文开放全文抽样确认** |
| 这些阴性能直接用于模型吗 | **能，但必须保留实验条件、阈值和证据位置** |
| 适合作为大创主场景吗 | **适合，推荐采用** |
| 最大风险是什么 | 图表抽取、实体对齐、数据库去重及避免伪阴性 |

**最终结论：将“转氨酶-底物相容性预测与酶选择”作为典型场景是有证据支撑的。该场景兼具公开benchmark、较高阴性密度、可验证的文献增量和明确的模型优化闭环，符合大创申报书“以典型任务形成通用方法框架，并拓展到其它重要问题”的要求。**
