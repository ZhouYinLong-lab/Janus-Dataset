# 候选领域调研 膜蛋白异源表达与纯化失败

最简调研 v1.0 | 2026-11-12 | 候选场景扫描，未经人工全量复核

## 一、场景定义

将膜蛋白从基因构建推进到可用于结构或功能实验的稳定样品，聚焦异源表达、膜插入、去垢剂溶解、亲和纯化、单分散性和稳定性失败。为了避免和“大肠杆菌重组蛋白表达与纯化”过度重叠，建议将范围限定为：**膜蛋白在不同宿主、构建体、去垢剂和脂质模拟环境下的条件性表达与纯化失败**。

## 三、初筛抽取结果

采用统一字段对正文、摘要、实验统计和图表说明进行快速匹配。膜蛋白论文常把阴性数据放在 FSEC 曲线、SDS-PAGE、免疫印迹或筛选矩阵中，因此文字抽取和图像抽取需要分层处理。

| 指标 | 初筛结果 |
|---|---|
| 代表性论文 | 5 篇，均有开放全文 |
| 候选证据线索 | 约 42 条，另有较多图像/曲线依赖线索 |
| 阴性类型 | 克隆失败、低表达、不溶、去垢剂不兼容、聚集、低纯化产率、功能不稳定 |
| 明确原因线索 | 约 29 条，常涉及疏水性、毒性、脂质不匹配和去垢剂稳定性 |
| 表格/图表依赖 | 高；FSEC、免疫印迹和条件筛选矩阵不能只靠正文文本恢复 |
| 对象字段 | 高；蛋白、构建体、宿主和标签通常可定位 |
| 条件字段 | 高；宿主、温度、去垢剂、脂质模拟物较明确 |
| 结果终点字段 | 中高；表达、溶解、纯化和稳定性有时使用不同指标 |

### 典型阴性证据

1. 早期标准表达条件下，只有少数目标达到可检测的膜定位或足够产量，提示“未检出”不能简单等同于序列无功能。
2. 同一膜蛋白在不同去垢剂中的溶解、单分散性和稳定性可能相反；最适合提取的去垢剂不一定最适合后续结构研究。
3. FSEC 中空体积峰大、包含峰弱或峰形异常，通常被用作聚集、降解或不稳定的负面信号。
4. 无细胞体系中 61 个真核膜蛋白只有 35 个在至少一种脂质模拟物中进入可溶部分，另外目标表现出条件性失败。
5. 脂质体、纳米盘和去垢剂的表现不同，说明“失败”必须绑定具体环境，不能只给蛋白一个永久负标签。

## 五、下游任务定义

**输入**：膜蛋白序列、构建体/标签、宿主、温度、去垢剂和脂质模拟环境；**输出**：表达、溶解、纯化和稳定性各阶段的结果预测，并排序推荐下一组条件；**标准答案来源**：同一论文内的平行筛选矩阵、FSEC/SEC 结果、免疫印迹或功能读出，经人工核查后形成条件化标准答案。

推荐先做多任务分类：

1. 表达是否达到可检测水平；
2. 是否进入可溶部分；
3. 是否形成可纯化、单分散、稳定的样品；
4. 在失败条件旁边推荐相邻的宿主、去垢剂或脂质环境。

## 六、与项目主题的匹配度

这个场景特别适合研究“阴性条件不是绝对负类”。同一膜蛋白在 A 去垢剂中聚集、在 B 去垢剂中稳定；在细菌宿主中不表达、在无细胞体系中可检测；同一构建体在小规模有峰、放大后失稳。这样的条件化失败信息比单个“成功结构”更能约束模型边界。

同时，文献中的阴性证据高度分散在实验方法、筛选表、FSEC 曲线和补充材料中，正好体现非结构化科学信息挖掘的实际难点。

## 七、主要风险与初步判断

| 风险 | 判断 | 处理建议 |
|---|---|---|
| 结果依赖 FSEC/胶图/免疫印迹 | 高 | 将图像依赖作为单独字段，不把图中未识别内容强行转成标签 |
| 表达、溶解、稳定性终点混用 | 高 | 采用分阶段多任务标签，禁止合并为一个“成功/失败” |
| 蛋白种类和构建策略异质性大 | 中高 | 先限定膜蛋白类别和实验体系，保留宿主/构建体上下文 |
| 条件组合空间过大 | 中 | 先做同一论文内的成组对照，再跨论文归一化 |
| 文献正结果多于负结果 | 中 | 优先抽取筛选矩阵中的未达标条件，区分“未测”和“失败” |

**初步判断：值得进入下一轮，但应作为第二优先级。** 它的科学价值和阴性证据密度很高，且模型任务清晰；主要短板是图像依赖和终点标准化难度高于蛋白质结构测定总流程。

## 八、下一轮核查建议

1. 先选择 3 种常见体系：大肠杆菌、哺乳动物细胞和无细胞脂质模拟体系。
2. 每篇论文至少抽取一个完整条件矩阵，保留成功、失败、未测三种状态。
3. 把 FSEC/SEC 峰形、免疫印迹强度和纯化产率分别标注，避免把“表达高”当成“结构样品质量高”。
4. 用同一论文内的相邻条件做验证集，测试加入阴性条件后模型是否能减少盲目实验。
