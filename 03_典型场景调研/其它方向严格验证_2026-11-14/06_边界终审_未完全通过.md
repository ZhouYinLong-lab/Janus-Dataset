# 蛋白质结构测定流程失败方向：边界终审结果

## 结论

**不能确认已经通过之前的全部边界。当前结论是“候选方向通过初筛，项目边界终审条件通过”。**

扩展样本证明该方向存在较多正文失败叙述，但“证据数量够”与“每条都是数据库外的非结构化阴性增量、且能在外部 benchmark 上验证价值”不是同一件事。

## 四项边界逐条检查

| 边界 | 当前结果 | 判断 |
|---|---|---|
| 正文自然语言、具体已实施实验 | 主要满足。YdeN、人工 coiled-coil、蛋白笼设计等条目有具体对象和实验动作 | 通过，但需对每条保留原文上下文 |
| 不依赖图表/表格/明确数值结果 | 只有约 5 个证据块可保守保留；MK2、TEV、CGD6、IF-1 等候选与后续 Figure/Table/数值救援结果关联 | 未完全通过 |
| 数据库外增量 | 失败原因、失败表型、救援动作具有明显增量潜力，但尚未逐条与 PDB、TargetTrack、CF_DS/CRYS_DS 对照 | 未验证完成 |
| 外部公开 benchmark 可验证模型价值 | 已找到 CF_DS、CRYS_DS 等公开训练/测试 benchmark；但尚未完成“基线 vs 加入文本增量”的模型对照 | benchmark 存在，价值验证未完成 |

## 保守核心与边界样本

### 保守核心

目前可以较有把握保留：

1. designed protein cage 原始构建体组装异质、无法原子级表征；
2. YdeN 野生型未获得晶体；
3. NHCC 初始构建体在溶液中无结构且未结晶；
4. C 端 GCN4-pII adaptor 下 degNHCC 仍无结构；
5. foldon 和含半胱氨酸重复的折叠救援动作失败。

这 5 个证据块来自 3 篇论文，足以支持“方向值得继续”，但不足以证明文献规模已经稳定达到可直接建库的程度。

### 边界样本

以下证据不能在当前口径下直接算核心：

- MK2 初始构建体和构建体 15/16 的结晶失败：同文中有 Figure/Table 和具体筛选结果；
- N-carbamoylsarcosine amidase 的 TEV 去标签失败：同一事件后面有蛋白酶救援和结构分辨率；
- CGD6_3220 多构建体结晶失败：同段后面有蛋白酶处理后的 2.2 Å 结果；
- IF-1 晶体优化失败：同一段有条件编号和后续成功晶体；
- MR 结构解析失败：属于计算结构求解边界，不是核心湿实验阴性数据。

## 还缺什么才能最终通过

### 1. 完成数据库外增量核验

为每条核心证据建立对照表：

| 证据字段 | PDB/TargetTrack/CF_DS/CRYS_DS 是否已有 | 若已有，正文新增了什么 |
|---|---|---|
| 目标蛋白/序列 |  |  |
| 构建体或突变 |  |  |
| 结晶/折叠失败状态 |  |  |
| 失败原因或表型 |  |  |
| 救援动作 |  |  |
| 后续结果 |  |  |

若正文只重复已有“未结晶”标签，不计为高价值增量；若正文补充了构建体、条件、原因或救援动作，才进入核心数据集。

### 2. 完成 benchmark 对照实验

已有工作将 TargetTrack 阶段标签整理为 MF_DS、PF_DS、CF_DS、CRYS_DS，并在公开训练集/测试集上做蛋白结晶倾向预测。下一步必须比较：

```text
结构化 benchmark 基线
vs.
结构化 benchmark + 正文非结构化阴性增量
```

比较指标至少包括 MCC、AUROC、阴性类别召回率，以及对“结构化标签相同但失败原因不同”的错误分析。

## 当前能写进申报书的强度

可以写：

> 蛋白质结构测定流程失败方向经扩展样本检索后显示出较高的正文阴性证据密度，是当前优先候选；项目将进一步核验这些失败叙述相对于公开结构化 benchmark 的增量，并在公开结晶倾向 benchmark 上验证其模型价值。
