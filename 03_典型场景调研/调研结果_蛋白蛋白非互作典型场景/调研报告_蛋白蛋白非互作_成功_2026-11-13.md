# 蛋白—蛋白非互作：典型场景验证报告

**日期**：2026-11-13  
**结论**：**成功，推荐作为大创申报书的首要典型场景。**

## 1. 场景定义

以科学论文中实验验证的蛋白—蛋白非互作或直接结合失败为典型任务，从自然语言中恢复：

```text
蛋白 A—蛋白 B—构建体/突变—实验方法—条件—非互作结论—原文证据
```

目标标签包括：

- 未检测到直接结合；
- 不能共沉淀或不能 pull-down；
- 仅通过第三方蛋白间接形成复合物，本身不直接互作；
- 突变或构建体导致原有结合消失或显著减弱；
- 互作只在特定条件、修饰状态或辅助蛋白存在时出现。

下游任务是蛋白—蛋白互作预测。抽取的实测非互作可替代随机配对负样本，用于训练、校准和检验模型的假阳性。

## 2. 公开 benchmark 与规模

| 资源 | 文献阴性规模 | 与本项目的关系 |
|---|---:|---|
| Negatome 1.0 | 1,291 个文献人工非互作对，来自 246 篇论文 | 提供蛋白对、PMID 和实验方法，可作为来源级金标准 |
| Negatome 2.0 | 2,171 个 Manual 文献非互作对 | 明确由文献人工核验形成；可用于训练和评价 PPI 模型 |
| Negatome 2.0 文本挖掘实验 | 2,134 个系统候选；人工确认 895 个蛋白—蛋白非互作，另有约 10% 在阅读全文时补充发现 | 直接证明自然语言抽取任务可执行，并提供候选精度和人工复核基线 |
| Flock 2026 文献子集 | 10,082 个可用文献非互作对，严格过滤后发布 8,706 对 | 使用 Europe PMC 论文和 LLM 筛选，证明现代全文中存在规模化自然语言非互作证据 |
| Flock 完整训练集 | 404,577 个无向蛋白对，其中 377,643 个负对 | 可直接构建 PPI 分类与共折叠 benchmark；文献阴性与结构阴性分源保存 |

Negatome 2.0 报告，最初的 58,733 个否定关系候选只有约 20% 是真实非互作；加入关系动词和语义过滤后得到 2,134 个候选，高分样本精度达到 95%，中位和低分样本明显下降。因此该任务既有充足数据，也存在值得研究的抽取与校验问题。

Flock 的 2026 年公开流程进一步从 Europe PMC 自然语言构建文献非互作集：10,082 个去重可用蛋白对经过跨论文矛盾、IntAct 正互作、结构正互作和已知结构负例过滤后，保留 8,706 个文献负对。该流程还指出，错误主要来自突变体、构建体、细胞系和间接复合物等条件被错误泛化为完整蛋白对，这与本项目拟研究的“上下文保持和证据校验”直接对应。

## 3. 五篇来源论文的严格全文抽查

本次从 Negatome Manual 数据中选取 5 篇具有 PMC 开放全文的来源论文。只统计正文自然语言已经明确给出两个蛋白实体和负向关系的记录；单纯无酶对照、方法失败、图表中未列出的批量名单和重复表述不计入。

| **合计** |  | **10** |

除上述 10 条外，PMC2876961 还报告 BICDR-1 在 60 种 Rab 蛋白筛选中只强烈结合 Rab6A/B、对其余多数 Rab 不结合。由于具体蛋白名单需要读取 Figure 3A，本次将其列为“图表待补全”，未用来增加正文有效数量。

该抽查不是随机密度估计，而是对公开 benchmark 来源链的核验。核验结果确认：数据库中的非互作对确实能够回溯到论文正文中的实验否定陈述，并且关系带有辅助蛋白、突变体、构建体和方法条件等数据库通常未完整保留的上下文。

## 4. 为什么比酶工程场景更合适

| 判断项 | 酶工程突变体阴性 | 蛋白—蛋白非互作 |
|---|---|---|
| 统一任务 | 活性、产率、选择性、表达和稳定性混杂 | 统一为蛋白对是否发生指定物理互作 |
| 标准答案 | 指标和阈值不统一 | Negatome 提供人工非互作对、PMID和实验方法 |
| 自然语言证据 | 很多结果只在 Figure/Table/SI | 正文常直接写 `does not interact`、`not co-immunoprecipitated`、`no direct binding` |
| 规模 | 当前严格样本密度低 | 2,171 个公开人工文献对；最新文献子集 8,706 对 |
| 模型用途 | 需要先统一多种功能端点 | 可直接替换随机负样本，训练和评价 PPI 预测模型 |
| 主要难点 | 数据稀疏和端点异质 | 否定范围、实体消歧、间接复合物、突变体/条件作用域，适合方法研究 |

## 5. 申报书推荐表述

> 本项目以蛋白—蛋白非互作识别与互作预测为典型应用场景。针对科学文献中“未检测到直接结合”“不能共沉淀”“仅通过第三方蛋白间接关联”以及“突变导致互作丧失”等非结构化阴性证据，研究蛋白实体识别、否定作用域解析、实验条件关联、证据定位与跨数据库冲突校验方法，构建带来源和条件的高可信非互作数据，并将其用于改进蛋白—蛋白互作预测模型的负样本质量、泛化能力与假阳性控制。在此基础上，将通用方法拓展到蛋白—小分子不结合、酶—底物不反应和其他生化阴性结果。

## 6. 成功/失败判断

| 条件 | 判断 |
|---|---|
| 有公开 benchmark | **成功**：Negatome、Flock及正互作数据库可形成对照 |
| 有较多真实阴性数据 | **成功**：2,171 个公开人工文献对；Flock 文献集 8,706 对 |
| 阴性来自自然语言 | **成功**：Negatome 和 Flock 均明确使用论文文本挖掘与人工核验 |
| 有数据库之外的增量字段 | **成功**：正文包含条件、构建体、突变、间接复合物和否定作用域 |
| 能驱动模型优化 | **成功**：实测非互作用于替代随机负采样并评价 PPI 模型假阳性 |
| 适合作为首要典型场景 | **成功，推荐** |
