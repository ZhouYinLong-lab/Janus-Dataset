# 非结构化阴性数据抽取：当前简化流程

现阶段采用队伍已经能运行的两段式方法，不把工程化管线作为前置条件。

```text
论文 PDF
  → PDF/API 提取原始文字
  → 按论文分别提交给网页大模型
  → 大模型列出候选阴性数据及原文证据
  → 人工删除无关项和图表重复项
  → 汇总每篇真正有效的数量
```

## 当前执行步骤

### 第一步：提取原文

使用现有 PDF/API 提取工具。输出应按论文分隔，并尽量保留页码、章节和原句。API 在这一步只负责文本获取，不负责判断阴性数据。

### 第二步：逐篇交给网页大模型分析

一次只分析一篇论文。使用 [quick_review_prompt.md](quick_review_prompt.md) 中的提示词，并附上该论文提取出的全部原文。

### 第三步：人工复核

只保留同时满足以下条件的记录：

1. 来自本文实际实施的生化实验；
2. 有具体酶或变体；
3. 有具体底物、反应或功能端点；
4. 有明确负向结果，例如无产物、无可检测活性、痕量产物、低产率或相对亲本明显下降；
5. 原文自然语言提供了实质信息，而不是只写“见 Figure/Table/SI”；
6. 能复制出原文证据并标明页码或章节。

删除以下内容：

- DFT、QM/MM、过渡态搜索或计算不收敛；
- FPLC、晶体电子密度、仪器和一般纯化问题；
- 无酶对照和仅用于机理说明的背景反应；
- 引言中引用的既往研究；
- 未测试、未报道或无法测量；
- 只存在于图表中、正文没有提供增量关系的信息；
- “没有改善”“较低”等缺少具体对象或结果的零碎评价。

## 输出口径

每篇论文分别报告三项数字：

| 指标 | 含义 |
|---|---|
| 原始候选数 | 大模型找到的所有负向描述 |
| 有效文本阴性数 | 人工复核后符合上述六项条件的记录 |
| 图表待补全数 | 有价值，但必须读取 Figure/Table/SI 才能结构化的记录 |

项目论证和数据量判断只使用“有效文本阴性数”，不得用原始候选数代替。

## 工程化脚本的定位

`pipeline.py` 保留为后续批量化工具，支持来源切分、候选扫描、结构校验和人工裁决。当前调研阶段不依赖它，也不能用 `prepare` 或关键词命中数声称已经获得阴性数据。只有经过人工复核并通过增量性判断的记录才可计入最终数量。
