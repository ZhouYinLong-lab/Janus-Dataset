# 生化文献非结构化阴性数据挖掘与利用

项目当前以酶动力学参数预测为典型应用场景，研究非结构化阴性实验信息的提取、整理、质量评价及模型利用，并计划拓展至蛋白质结晶预测等生化任务，交付可运行的原型系统。

当前项目内容见[大创申报书](01_项目申报/01_大创申报书.pdf)，研究背景见[文献综述](02_文献综述/01_文献综述.pdf)。这两份文件由团队于本轮整理前提供。

## 使用管线

具体步骤见[管线说明](04_通用阴性证据抽取管线/README.md)。从仓库根目录运行离线测试。

```powershell
python -m unittest discover -s "04_通用阴性证据抽取管线" -p "test_pipeline.py" -v
```

历史脚本采用原目录内部布局，运行时将工作目录切换到 06_历史调研。历史记录里的绝对路径和原始运行日志保留当时的内容，复用时将原仓库根目录下的 research、reproduction 等路径定位到该目录。

## 文件维护

当前申报书和综述分别更新到前两个目录。调研结果放入第三个目录，并在文件名中标注主题和日期。通用脚本与领域适配器分别维护。

.env、本地缓存与临时文件由根目录忽略规则排除。历史调研沿用整理前已进入 Git 的文件范围，本地模型、语料和运行缓存留在本机。
