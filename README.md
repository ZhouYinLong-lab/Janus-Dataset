# Janus-Dataset

面向 AI-ready 分子科学数据集的阴性数据研究与构建。

## 研究方向

关注分子科学文献及其衍生数据中阴性、失败和低性能结果的缺失，以及这些缺失对分子机器学习数据质量和模型表现的影响。

这里的阴性数据不是“坏分子”，而是与具体任务、性质和实验条件相关的观测，包括无活性、低性能、失败结果和相对劣化等。

## 当前问题

- 阴性结果在现有文献和数据库中的缺失程度如何？
- 缺失的阴性证据会怎样影响模型的训练、泛化、排序和校准？
- 如何从文献及其他数据源中提取、整合并评估这些证据？

## 状态

项目处于调研启动阶段，研究对象、边界和数据来源仍在梳理中。
