# NegBioDB 竞争工作审查（公开材料初审）

**审查日期：2026-09-30**  
**目的：** 判断 NegBioDB 对“分子科学阴性数据、文献恢复和模型效用”主课题的实际重叠，而不是依据标题或总记录数直接判定新颖性已被覆盖。  
**证据限制：** 当前检查了 Hugging Face 搜索索引中的数据卡、可见的配置文件，以及作者公开的安全/开放说明；匿名请求 Hugging Face 数据集树 API 返回认证错误，因此没有取得并重跑完整代码、逐条数据或完整模型预测，也没有看到正式投稿稿件。以下涉及规模和 benchmark 的内容，如注明“数据卡自报”，不代表独立复现。该 API 结果说明本环境无法验证匿名文件访问，不单独证明数据仓库一定是私有或永久受限。

## 初步判断

NegBioDB 是一个**必须正面对照的近邻/竞争项目**。它使“整合多领域 negative data、发布资源、跑 ML/LLM benchmark”的宽泛主张明显更难成立；但现有公开材料尚不能证明它已经解决“从原始论文恢复带 assay 语境的阴性证据”，也不足以证明其不同领域的 negative 是同一类证据或其性能改善由阴性证据本身导致。

所以目前既不能说“这个方向没人做”，也不能说“NegBioDB 已经做完了我们的精确问题”。当前 gap 必须按**来源类型、证据状态、语境粒度、可复核性和评价目标**比较。

## 与 Janus 候选问题的对应

| 研究环节 | NegBioDB 已覆盖/声称覆盖 | 我们仍需独立证明的部分 | 当前关联判断 |
|---|---|---|---|
| 是否存在 inactive / failed data | 多个结构化数据库和筛选/试验资源已有相应记录 | 某个具体领域/任务中有哪些记录仍在论文正文、表格或补充材料而未进入现有库 | 不能再从“缺少负数据”泛泛立题；转成覆盖差异量化 |
| 获取与融合 | 多源 ETL、实体汇总、多个领域标签资源 | 是否能可靠读取原文陈述，连回被测实体、assay、条件、阈值、来源页/表格及否定适用范围 | 文本—实验语义链接尚未由公开材料证明 |
| 标签可信度 | 有一些置信层级和阈值操作定义 | 建立可审计的状态本体：实测阴性、低于检测限/删失、失败、未测/未知、推定；不将零证据等同于实测阴性 | 可形成明确技术问题，但需要避免只改 schema |
| 模型价值 | 有多个模型和拆分结果自报 | 等样本量/等类比例对照下检验新增的、带上下文的文献阴性是否有独立增益；外推到 scaffold/time/assay OOD | 目前是关键未验证主张 |
| 泛领域主张 | 已有五域框架的公开自述 | 证明一个通用方案确实跨域成立的统一语义和可比指标 | 对本科生项目风险很高，不应直接以“覆盖所有分子科学”起步 |

## 新颖性和可行性结论（暂定）

1. **不可再主张：** 第一次建跨域 biomedical negative-resource；第一次收集 inactive 数据；第一次做负例 benchmark；第一次比较模型在负例上的表现。
2. **可能仍值得研究：** 对单一、公开且有清晰 assay 的分子任务，量化从论文/SI 恢复的**新增实测阴性观察**占多少、状态误判率多高、现有 ChEMBL/PubChem/BRENDA 等是否已有同一记录，以及原始上下文能否保留。
3. **模型因果问题须隔离：** 先固定 test set、训练数据量、positive:negative 比例及分子相似度分布；再比较数据库现有负例、文献找回的有证据负例、推定负例和不使用负例。否则只能说某一总体管线得分不同，不能说收益来自 negative evidence 的真实性或上下文。
4. **建议的 Go/No-Go 小试：** 取 50–100 条公开论文/SI 观察，人工复核实体、assay、状态、条件和出处；计算抽取 precision、相对公共数据库的增量覆盖、状态判定一致率和每条复核工时。若增量接近零或状态无法可靠区分，应调整课题，不扩成通用系统。
5. **NegBioDB 的下一步监测：** 查看公开的 commit-pinned 更新与后续投稿/预印本；若全文仍未开放，则把它作为高风险竞争项目记录其公开自述，但不对不可见实验结果作结论、不请求访问、不联系作者。

## 证据等级

- **可直接核对：** Hugging Face 可见数据卡与 YAML 配置中的范围、阈值、来源名、benchmark 名称。
- **作者自述、未独立复现：** 规模总计、模型结果、ML/LLM runs 数量、publication-bias 相关结论。
- **缺少的关键证据：** 原始论文全文/补充材料抽取的规则和比例、每个域标签的原始数据链接与状态分布、逐记录证据片段及误差审计、完整测试集与模型输出、独立复现。当前匿名 API 认证失败；不尝试使用任何个人凭据或请求受限访问。
