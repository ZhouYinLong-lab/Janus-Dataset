# 典型应用场景：分子胶降解剂研究

## 一、场景说明

本项目以**分子胶降解剂研究**作为非结构化阴性数据挖掘的典型应用场景。

分子胶能够促进目标蛋白与E3泛素连接酶形成相互作用，使目标蛋白被降解。现有数据库和论文摘要通常重点记录成功降解蛋白的化合物、靶标和活性指标，而没有产生预期效果的实验经常只在论文正文、图注或补充材料中简短出现。

常见情况包括：

- 某种化合物未能诱导目标蛋白降解；
- 同一种化合物只在部分细胞系中有效；
- 在特定剂量或处理时间下未观察到蛋白下降；
- 改变靶标、E3连接酶或实验条件后，降解效果消失；
- 与有效化合物结构相近的类似物没有产生相同作用；
- 实验效果较弱或未达到统计显著水平。

这些结果能够说明分子胶的作用范围和失效条件，但它们表达形式不统一，实验对象、条件和结果也可能分散在不同段落中，因此难以直接进入数据库或用于模型分析。

## 二、需要恢复的信息

项目从论文正文、图注和可用补充材料中寻找已经实施但没有获得预期结果的实验，并恢复以下信息：

| 信息类别 | 具体内容 |
|---|---|
| 化合物 | 分子胶名称、编号、类似物或对照化合物 |
| 实验对象 | 靶蛋白、非目标蛋白、突变体等 |
| E3连接酶 | CRBN、DDB1等相关蛋白 |
| 生物体系 | 细胞系、体外体系或动物模型 |
| 实验条件 | 剂量、处理时间等 |
| 实验终点 | 蛋白降解、蛋白丰度、结合、mRNA变化或细胞增殖 |
| 观察结果 | 未观察到作用、作用较弱、无显著差异或条件性失效 |
| 检测方法 | Western blot、流式细胞术、蛋白质组学等 |
| 原文出处 | 论文、段落、句子、图注及引用位置 |
| 质量状态 | 可靠、待确认或排除 |

项目只纳入**已经开展并报告结果的实验**。未测试、未提及、方法描述和模型推测不作为实验阴性；“未达到统计显著”“效果较弱”和“完全未观察到作用”分别记录。蛋白降解、mRNA变化、细胞增殖、结合和酶活性等终点也分别处理。

## 三、方法流程

```text
论文收集与正文解析
        ↓
阴性实验候选发现
        ↓
实验对象、终点和结果方向恢复
        ↓
剂量、时间、细胞系等条件恢复
        ↓
原文引用与位置核查
        ↓
重复实验归并与质量分区
        ↓
结构化数据导出
        ↓
RAG和结构化预测利用
```

每条记录保留论文信息、原文位置和修正历史。正文、图注和补充材料对同一实验的重复描述可以保留为多个证据位置，但在实验层面只统计一次。对象、终点或条件无法确认的记录进入待确认集合，不直接用于模型实验。

## 五、应用效果

### 5.1 总体结果

| 实验 | 主要结果 | 说明 |
|---|---|---|
| 直接证据版RAG（78题） | 恢复证据0.897；原文0.799；结构化资料0.291 | 问题直接对应证据时，恢复记录便于模型定位答案 |
| 提高难度版RAG（57题） | 恢复证据0.404；原文0.673；结构化资料0.327 | 恢复证据优于结构化资料，但压缩记录会丢失比较对象和实验条件 |
| Qwen3-0.6B LoRA | 基座41/57；仅阳性41/57；领域对照42/57；平衡阴性41/57 | 当前小参数语言模型微调没有显示阴性数据增量 |
| MG2Act结构化回归 | ExtraTrees MAE 0.0959；Ridge 0.1168；training-free语言模型0.2895 | 结构化X→Y预测更适合任务专用模型 |
| 阴性平衡分类 | 恢复阴性组的阴性误报率为26%—40%；结构化阴性组为61%—91% | 恢复阴性改变了分类边界，减少了把阴性实验误判为阳性的情况 |

### 5.2 提高难度版RAG

提高难度版RAG设置57道问题，每道题分别使用不同信息来源回答。

| 信息来源 | 平均得分 |
|---|---:|
| 不检索 | 0.315 |
| 结构化资料 | 0.327 |
| 等长背景材料 | 0.322 |
| 恢复阴性证据 | 0.404 |
| 论文原文 | 0.673 |

恢复阴性证据相对结构化资料提高0.063，95%区间为0.025至0.107。题目级比较中，恢复证据相对结构化资料有11题改善、44题持平、2题退步；相对论文原文有5题改善、20题持平、32题退步。

该结果表明，恢复后的证据能够补充结构化数据库缺少的失败情境和作用边界，但当前压缩记录还不能替代完整原文。主要信息损失集中在结果方向、比较对象和实验条件。

### 5.3 小参数语言模型LoRA

| 模型 | 正确数 | 准确率 | 过度推断率 |
|---|---:|---:|---:|
| 未训练基座 | 41/57 | 71.93% | 19.30% |
| 仅阳性训练 | 41/57 | 71.93% | 21.05% |
| 领域材料对照 | 42/57 | 73.68% | 19.30% |
| 平衡阴性训练 | 41/57 | 71.93% | 21.05% |

四组模型共同答对41题、共同答错15题，只有4题产生不同预测。平衡阴性训练没有提高正确数，也没有降低过度推断率。该实验保留为开发记录，说明简单微调小参数语言模型没有形成稳定的阴性边界能力。

### 5.4 传统模型与阴性平衡

传统分类实验使用54个高置信阴性实体单元，来自41个实验和23篇论文。与只使用已有结构化阴性的平衡组相比，加入正文恢复阴性的模型取得以下变化：

| 指标 | 变化 |
|---|---|
| 准确率 | 提高1.1—3.6个百分点 |
| 宏F1 | 提高0.064—0.116 |
| 阴性误报率 | 从61%—91%下降到26%—40% |
| AUROC | 下降0.015—0.037 |

恢复阴性的主要作用是减少模型对阴性实验的过度阳性判断，而不是同时提高所有指标。这一结果与“阴性证据帮助模型认识作用边界”的研究假设相符。

## 六、具体案例

1. **β-catenin降解**：恢复证据组得分为1.0，结构化资料和背景材料均为0.333。正文阴性补充了数据库没有表达的突变体作用边界。
2. **E7820与线粒体呼吸**：论文原文组得分为1.0，恢复证据组为0.333。压缩记录遗漏了比较对象和实验条件，模型无法完整回答。
3. **LXH-3-71与PHGDH**：四个语言模型组都把酶抑制问题误答成蛋白降解，说明不同实验终点容易被混用，加入阴性LoRA没有解决这一问题。

## 七、拓展方向

在分子胶场景中完成方法验证后，同一框架可以拓展至：

- PROTAC等其他靶向蛋白降解研究；
- 药物活性和药物敏感性评价；
- 酶抑制实验；
- 生化反应条件筛选；
- 其他存在大量正文阴性结果的生化任务。

不同任务可以共用文献解析、证据定位、来源追溯和质量验证流程，再根据实验类型调整需要恢复的对象、条件和结果字段。

## 八、申报书概括

> 本项目以分子胶降解剂研究为典型应用场景，重点挖掘论文正文、图注及补充材料中未诱导靶蛋白降解、仅在特定细胞或实验条件下失效等非结构化阴性结果。项目将建立包括文献解析、阴性证据识别、实验对象与条件恢复、原文定位、质量验证和实验归并在内的通用方法框架，形成可追溯的结构化实验记录。在此基础上，通过检索增强和结构化预测对照实验，检验恢复的阴性证据能否帮助模型认识分子胶的作用边界、减少对实验效果的过度推断。完成分子胶场景验证后，再将该方法拓展至其他靶向蛋白降解、药物活性评价和生化实验任务。
