# 初步范围综述与汇报材料

本目录汇总当前阶段可以直接使用的书面产出。研究范围暂定为小分子与蛋白靶点的生物活性数据，重点关注实验阴性结果的缺失、恢复和机器学习价值。

## 文件

- [`scoping_review.md`](scoping_review.md)：完整的初步范围综述，包含检索边界、证据综合、现有工作、研究空白和可行方案。
- [`briefing_notes.md`](briefing_notes.md)：约 8 分钟的短版汇报提纲，可直接据此口头说明。
- [`claim_evidence_matrix.csv`](claim_evidence_matrix.csv)：逐条记录核心主张、证据、反证或限制和当前置信度。
- [`evidence/`](evidence/)：对结论影响较大的新增论文及来源说明。

## 当前结论

已有工作已经完成了四块关键拼图：利用阴性生物活性数据训练模型，建立 inactive 化合物资源，保存完整筛选流程中的正负结果，以及从论文中自动抽取定量生物活性。2026 年的 BioMiner 尤其接近“文献抽取加模型验证”这一设想，因此大规模抽取生物活性本身不能再作为主要新意。

目前仍有研究空间的是阴性证据的专门表示和评价：区分实测 inactive、阈值截断、定性无效、相对变差、实验失败、推定阴性、人工 decoy 和 unknown；保留原文位置与 assay 条件；再通过严格对照检验这些信息是否改善模型在新骨架、新 assay 或时间外推场景中的表现。

这是一份范围综述，不是穷尽式系统综述。新颖性表述应使用“本轮检索尚未发现”，不应写成“此前无人研究”。
