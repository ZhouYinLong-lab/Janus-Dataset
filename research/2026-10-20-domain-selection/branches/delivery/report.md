# LNP递送/稳定性：首次试做选域判断

日期：2026-10-20。结论：**不推荐作为首次试做；保留为有递送专业合作时的稳定性证据补全备选。** 数据丰富不等于起步简单。原始实验确有可恢复的弱结果，但泛化为“无效脂质”会丢失比较基准、储存历史、载荷和测量条件。下面只用5个primary资源；没有调用模型API、训练、安装或生成新分子。

主agent提供的新背景是TPD已有可raw读取的7篇/104条MG、15篇/209条PROTAC金标；此项由主agent核实，本分支未重查、不将其算入5个来源。在“先复现通用API模型补字段”这一目标下，有现成金标的路线比本轮尚无阴性金标的LNP更易验收；这不是对TPD生物学难度的判断。

## 2. 可审计的弱结果及字段位置

### S1：储存导致表达下降，但仍非零

[原始全文XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC7078456/fullTextXML)，DOI：[10.1016/j.bioactmat.2020.03.001](https://doi.org/10.1016/j.bioactmat.2020.03.001)。

- §2.2提供TT3、DOPE、cholesterol、DMG-PEG2000及其原始摩尔比20/30/40/0.75。这个比值不是加和100的mol%；需要保留组分顺序和“比值”类型，不能机械当百分比。
- §2.3提供Hep3B、FLuc mRNA、50 ng mRNA/well、给药后18 h读luciferase。储存时长与18 h检测时间是两个字段。
- §3.1及Fig.1B：4°C水相储存，相对新鲜LLN的表达一周70.1%、五个月5.4%。这是**相对表达衰减**，5.4%不是零，也不是“5.4%的细胞转染阳性”。n=3来自图注；具体时间点的p值不能由统一图注反推。
- §2.4 + §3.2/Fig.2B：三次冻融后，5%或10% mannitol组仅保留约60%表达。应标“低于新鲜对照、仍有残余表达”，不是全无效；冻融次数、保护剂最终浓度和检测协议要跨段连接。
- §2.6–2.7 + §3.4–3.5/Fig.4–5：冻干样品在合适保护剂条件下体外表达相近，但体内读数显著低于新鲜对照。结论措辞更强，数据层应保留“体内降低、数值待图核查”，不能拿体外结果填体内列，也不能把作者概括自动转成零。体内为C57BL/6、静脉给药、0.25 mg/kg、6 h，不能套用Hep3B的50 ng/well、18 h。

### S2：外观稳定不代表功能稳定；n.s.不代表无效

[原始全文XML](https://www.ebi.ac.uk/europepmc/webservices/rest/PMC10062427/fullTextXML)，DOI：[10.1016/j.jconrel.2023.03.039](https://doi.org/10.1016/j.jconrel.2023.03.039)。

§2的制备、冻干和细胞转染方法，与§3.1/Fig.2一起给出C12–200体系、PBS/Tris/phosphate、脂质:mRNA质量比、保护剂、HEK293T、eGFP、理论0.5 μg/well和24 h读数。§3.1明确报告PBS条件下包封率由85%到58%（质量比10），另一组由92%到72%（质量比20）；这是**包封率**，不是转染率或“失效率”。同段报告PBS转染下降，但“±30%”表述不够明确，本轮不转为精确绝对/相对百分比。

§3.3/Fig.4显示冻干phosphate组4°C储存一周后转染减弱；粒径没有显著增加，不能据此判功能未变。Fig.6图注的n.s.及正文描述对应新鲜和冻干样品的比较，意为未检出组间差异，**不是两组都无效，也不是严格等效性检验**。本轮未从图像读取n.s.连线的全部组别，evidence.csv保留该限制。

本轮确认的是条件相关的下降、残余表达和未检出组间差异，没有核实到带检测下限定义的“绝对零表达”金标。不能为满足“阴性”目标创造这种标签。

## 3. 与已有工作的实质重叠

**LipoAgent/TransLipid是prior，不是本项目模型收益。** [全文](https://arxiv.org/html/2605.25250v1)§4称约1,200条文献效率记录与400条毒性分子整合为1,600条，按1–10效率等级评价并使用人工介入；§4.4确有B16F10中四个候选的高/中/低实验排序。它直接占据“文献脂质数据→小参数语言模型效率预测/排序”的宽路线。低分不是有检测限的零表达，毒性分子也不能自动并入转染失败类。本分支不转述其性能增益为我们的预期。

公开repo的build_dataset.py明确从Qwen/TxGemma预测标签构建训练集并随机切分；这与论文陈述的实验TransLipid不能直接画等号。README列的virtual_library.xlsx返回HTTP 200，而尝试的data/finetune/train.jsonl返回404；两个常见根LICENSE路径也404、GitHub API受限。这里只证明**已查路径不能交付完整实验金标链**，不声称作者未发布任何其他版本。虚拟库、模型标签、实验标签必须区分；复用其模型解释不能当人工金标。

**LNP Atlas已经非常接近导师的补表安排。** [论文](https://doi.org/10.1038/s41597-025-06456-w)明确使用Claude读全文、统一JSON、人工修正部分图；Table 1及CSV含组成、SMILES、制备、细胞/动物、剂量和活性信息。故“通用LLM提LNP字段”本身缺乏新颖性。本轮真实读取CSV；按两篇实验DOI和标题关键词查找均0行命中，只说明这一版未匹配到S1/S2，尚未完成同义名及逐条溯源审计，不能据此宣称发现全新数据空白。

**LNPDB对筛选面板已有规模覆盖。** [论文](https://doi.org/10.1038/s41467-026-68818-1)报告19,528配方及269商业脂质，公开CSV实读19,797行，数量与二者相加一致。它含实验值与条件，且从热图/柱图数字化；按论文/实验上下文标准化。CSV中10,754行Experiment_value以负号开头，这只是字符串符号统计，**不是10,754条实测无效样本**。例如LNP_0000081为-0.366886147，方法列是luminescence_discretized_normalized；负值不能当负浓度、零表达或统计显著无效。该例载荷为siRNA，沉默读数方向还需另行确认，不应混进mRNA表达判断。

S5当前CSV字段中未见独立的储存温度、储存时长、冻融次数列；这仅表明存在做稳定性观察级补全的可能，不证明其文本字段或其他发行件没有相关信息。论文所说模拟中的bilayer stability也不能等同货架储存稳定性。

## 4. 补Excel字段的可行边界

用户未指定本次需补的Excel文件和表头；没有把仓库任意旧Excel冒充目标模板。下表是**待映射字段**，并非已填完用户Excel。实测证据在evidence.csv，每条均有定位和留空原因。

| 待映射字段 | 可核查位置 | 主要错误风险 |
|---|---|---|
| paper DOI、figure/panel、observation ID | XML元数据、结果段、图注 | 只留DOI无法追到一条观察 |
| lipid name、组分及顺序、ratio type | S1 §2.2；S2 mRNA LNP production | 比值与mol%混淆；不同组分顺序 |
| cargo/reporter、修饰、序列状态 | S1 §2.1–2.3；S2 IVT及转染方法 | FLuc/eGFP混合；名字不等于已获得完整序列 |
| cell/animal、route、dose、assay time | S1 §2.3/2.7；S2细胞/体内方法 | ng/well与mg/kg；18/24 h与储存月数混淆 |
| storage state、temperature、duration、cycles、protectant、buffer | S1 §2.4–2.6 + §3；S2冻干方法 + §3 | 母液浓度代替最终浓度；冻融与长期冷冻混合 |
| endpoint、value、unit、comparator、normalization | S1 Fig.1B/§3.1；S2 Fig.2/§3.1 | relative luminescence、%GFP+、MFI、包封率互换 |
| n、error type、test、p/LOD、claim type | 图注与统计方法；检测限未核实 | n.s.误记无效；未报告记为0 |
| evidence spans、source type、review status | 本文/图注/SI各自留定位 | 用方法中的共享协议覆盖例外样品 |

首批如果只抽常用命名脂质及报告基因，不必立即从分子图恢复结构；遇TT3或自制脂质时可保留作者ID及“结构未核验”。要做跨文献化学实体归一、SMILES监督或结构预测，常需原始分子图、补充合成信息或专门核对，通用文本API不足以保证正确。粒径/PDI与形态图的解释也有专业门槛。复杂载荷、序列修饰、不同细胞、活体剂量、测量终点和时间会显著增加连接难度，不能靠一个“transfection efficiency”列消除。

## 5. 原文件、许可、SI与下游用途

S1全文公开但标注CC BY-NC-ND 4.0；S2 XML是Elsevier COVID资源中心研究再用许可，非无条件CC BY。S4论文为CC BY-NC-ND 4.0，而实际Zenodo数据条目独立标注CC BY 4.0；必须分开记录。S5论文CC BY 4.0、repo LICENSE是MIT；两者不自动覆盖其全部上游原图。S3 arXiv HTML显示CC Zero，但未核实到repo数据的明确许可。这里记录实际许可标识，不给出训练或重分发的法律结论；发布全文片段、改编图、训练衍生物前需机构数据/版权负责人复核。

S1/S2可读取机器可解析全文及图注；各有mmc1.docx元数据，两个SI接口均超时，故补图本轮未读。S2原始数据声明是按请求提供，不能把“论文公开”写成“全套原始实验数据可直接下载”。S5有SI PDF链接与source-data声明，本轮未下载这些附件；已读取CSV并不等于复核其所有上游原图。完整URL及访问结果在sources.md。没有额外保存原文或附件到共享sources目录。

**RAG问题示例：** “Zhao 2020是否支持‘4°C存放五个月后TT3颗粒完全无效’？给出读数、对照，以及细胞、剂量、检测时间；哪些字段仍需原图复核？”预期检索S1 §2.3、§3.1和Fig.1B，回答5.4%是相对新鲜对照的剩余表达，证据不支持绝对零。答案必须引用这些段落，不向其他配方外推。

**小LLM任务示例：** 给定检索到的上述方法、结果和图注，输出观察级JSON/表格字段，并区分relative_decrease、no_detected_difference、below_detection、not_reported、uncertain；缺少LOD或准确p值时留空。这里是语言基座模型的抽取/证据判断任务，不是新分子设计或跨细胞效率预测。SFT、继续预训练等训练方式未定，本轮不替导师决定，也不承诺增益。

如果未来启用API抽取，应先用专业双人复核的小金标测字段准确率、跨段链接、阴性语义误标和正确拒答；再比较不检索/检索、仅结果/补方法图注，按论文隔离评价。只有这些任务需要比较才能知道是否改善，不能用prior的模型表现代替本项目验证。

## 6. 为什么否决首次试做、何时再考虑

首次试做当前需要可直接验收的金标和清晰字段；LNP虽有真弱结果，但本轮没有现成稳定性阴性金标，SI读取不完整，数据又常藏在图和聚合文本。宽路线被Atlas、LNPDB、LipoAgent明显覆盖；新贡献若存在，应是**观察级稳定性证据、对照与语义的可靠补全及其评估**，不是再建通用脂质表。做该窄任务还需递送专家裁决“较低但有表达”、体内外冲突、测量方向、细胞死亡与效率的关系、分子身份和剂量归一。本轮不能独立解决这些专业问题。

所以不建议把LNP抬到有可读金标的复现候选之前。若以后有递送合作者、可读附件与授权清晰的金标，S1/S2可作为小范围补全试题起点；本报告不将这个备选表述为已经证实的数据集新颖性或训练收益。蛋白表达溶解性本轮未另开检索，未形成与LNP同深度比较。
