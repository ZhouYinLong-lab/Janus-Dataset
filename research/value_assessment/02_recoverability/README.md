# 主张二：阴性证据能否可靠恢复

## 主张

可以从论文正文、表格、图像和补充信息中恢复阴性或失败观察，并把结果转换为带来源定位和实验上下文的结构化记录；在可接受的专家复核量下，精确率和召回率足以支撑数据集建设。

## 当前判断

`partially_supported`。

化学文献抽取本身已经有较强技术基础。ChemDataExtractor 对若干实体和属性任务报告了 86.8%–93.4% 的 F-score；ChemMiner 在 326 条专家标注反应上报告平均 precision 90.15%、recall 77.13%、F1 83.11%；ReactionSeek 对 Organic Syntheses 的关键参数报告超过 95% 的 precision 和 recall。这些结果说明多模态、跨段指代和反应条件抽取可行。

但这些基准主要抽取“已明确报告的反应与属性”。它们没有充分检验更困难的语义边界：未提及不等于失败，未检测不等于无活性，低于检测限不等于绝对不存在，筛选阴性也不等于分子全局惰性。因此，现有证据支持“抽取管线可建”，尚不能证明“阴性证据可直接自动化高质量恢复”。

## 可靠恢复的最低要求

一条记录至少应包含：

- 文献、页码/段落、表格或图编号和原始证据片段；
- 被测试实体、目标、操作、条件、测量方法与检测限；
- 结果类型：`inactive`, `failed`, `no target product`, `below detection`, `inconclusive`, `relative decrease`；
- `not tested` 与所有阴性类别严格分离；
- 抽取器版本、置信度、规则/模型输出和人工复核状态；
- 对跨句指代、图表和补充信息的链接。

## 必做的验证

建立由领域专家双人标注的小型金标准，按“文档 → 候选证据 → 观察记录 → 上下文字段”分层计分。除 entity-level precision/recall/F1 外，还需报告文档级漏检率、否定范围错误、条件绑定错误、证据定位正确率和标注者一致性。测试集应按期刊或时间外切分，避免模板泄漏。

## 暂定停止条件

如果在至少两个领域中，经过一轮主动学习后仍无法把关键阴性类别的 precision 提高到 0.90 左右，或每条记录的专家复核时间接近从头人工录入，则不宜直接建设大规模统一数据集，应退回到半自动证据检索工具。
