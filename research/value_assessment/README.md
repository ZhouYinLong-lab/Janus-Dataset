# 项目价值的四条证据链

本目录用于回答一个比“能不能收集阴性数据”更严格的问题：是否值得建设一个跨分子科学领域、从文献中恢复阴性证据、保留实验上下文，并通过下游任务验证价值的数据集与方法。

这个判断被拆为四个可以分别证伪的主张：

1. [`01_problem_exists`](01_problem_exists/)：现有公开数据是否确实遗漏、压缩或误表征了阴性结果；
2. [`02_recoverability`](02_recoverability/)：文献中的阴性证据能否被稳定、可审计地恢复；
3. [`03_model_utility`](03_model_utility/)：加入这些数据是否能改善模型，而非只增加样本量；
4. [`04_cost_benefit`](04_cost_benefit/)：达到可用质量所需的人力、计算和版权成本是否合理。

## 统一判断口径

每条证据记录都区分三种直接程度：

- `direct`：研究对象、方法和被检验主张基本一致；
- `partial`：只覆盖一个领域、数据类型或管线环节；
- `contextual`：说明背景或风险，但不能直接证明该主张。

阶段性结论使用 `supported / partially_supported / unresolved / contradicted`。论文中的结果与本项目的推断分开记录；没有跨领域证据时，不把单一化学任务的结果外推到“所有分子科学领域”。

## 当前快照

| 主张 | 暂定结论 | 主要缺口 |
| --- | --- | --- |
| 问题真实存在 | `partially_supported` | 子领域证据充分，但“跨全部分子科学”的缺口尚未系统量化 |
| 阴性证据可恢复 | `partially_supported` | 一般化学信息抽取已较成熟，专门针对阴性、未测试与失败原因的基准仍缺失 |
| 能改善模型 | `supported_in_specific_tasks` | 已有合成与生物活性案例，尚不能证明统一数据集在跨任务上稳定增益 |
| 成本收益合理 | `unresolved` | 自动抽取已有显著提速案例，但阴性证据的专家复核成本尚无实测 |

本轮材料是可继续扩展的初步证据包，不是最终系统综述。检索截止日期为 2026-09-04。

本地论文的文件大小、来源和 SHA-256 校验值见 [`paper_manifest.csv`](paper_manifest.csv)。
