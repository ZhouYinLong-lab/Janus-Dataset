# 主张四：成本收益是否合理

## 主张

在达到可审计数据质量的前提下，自动检索、抽取和主动学习能够把每条有效阴性观察的边际成本降到人工从头整理以下；由数据带来的模型或实验决策收益足以覆盖抽取、复核、存储、许可和维护成本。

## 当前判断

`unresolved`。

自动化抽取具有明显降本潜力。ChemMiner 的同一实验表中，人工收集 precision 为 90.05%、每条反应约 288 秒和 1.41 美元；其 agent 为 87.45%、0.43 秒和 0.0025 美元。这个结果说明候选抽取可以非常便宜，但它没有计算阴性语义判定、专家复核、全文获取、去重、条件规范化和长期维护成本。

ReactionSeek 与 ChemDataExtractor 进一步说明自动抽取可以扩展到较大文献集。它们仍不能直接给出本项目的单位成本，因为阴性记录更稀疏，且错误标签的风险更高。

## 应使用的价值模型

不要只比较“人工分钟”和“API 费用”。建议按下式记录一次试点：

```text
每条可用记录成本 =
(检索 + 全文获取 + 模型推理 + 专家复核 + 争议仲裁 + 规范化 + 维护)总成本
/ 通过质量门槛且可合法发布的唯一观察数
```

同时记录：

- 每 1000 篇文献的候选命中数、唯一有效记录数和领域分布；
- 每条候选与每条最终记录的人工分钟数；
- 各阴性类型的 precision、recall 和仲裁率；
- 无法获取全文、许可不清和无法发布原文片段的比例；
- 下游每增加一个有效百分点所需的记录数和复核成本；
- 数据更新频率、模式迁移与链接失效维护成本。

## 试点设计

先抽取 200–500 篇开放获取论文，覆盖两个领域。前 50 篇双人全量标注以估计召回率，剩余文献采用模型候选加单人复核，并随机抽取阴性预测和模型未命中文档做审计。只有在单位有效记录成本、错误率和下游增益三者同时可接受时才扩大规模。

## Go / No-go 参考线

以下不是既定事实，而是便于决策的初始阈值：

- 关键类别 precision ≥ 0.90，文档级 recall ≥ 0.75；
- 中位专家复核时间 ≤ 2 分钟/最终记录；
- 至少 70% 最终记录能够发布结构化字段、来源定位和短证据片段；
- 至少一个严格外部测试中优于强负例基线，且增益在重复实验中稳定；
- 若许可与全文可访问性使大多数记录不能复核或发布，停止扩张，转向开放语料或数据合作。

这条证据链最需要真实试点数据。现有论文只能给抽取速度的上界参考，不能替代本项目核算。
