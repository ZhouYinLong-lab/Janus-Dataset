# 主张一：问题是否真实存在

## 主张

现有分子科学数据资源对阴性、失败或无效观察的保存并不充分，而且常将实验上下文压缩为脱离条件的二元标签；这种缺失或压缩会限制模型对失败边界、适用域和真实实验分布的学习。

## 当前判断

`partially_supported`。

“阴性数据在若干重要子领域被遗漏、低利用或不恰当地构造”已有较强证据。失败材料合成、药物靶点活性、虚拟筛选和化学生物筛选均有直接先例。与此同时，InertDB、ECBD、ChEMBL/PubChem 派生数据和 CARA 说明已有资源正在保存或利用阴性记录。因此，不能把研究空白表述为“此前没有阴性分子数据集”。

更可信的空白是：尚未看到一个跨领域、以观察为单位、同时区分 `not tested / inactive / failed / inconclusive / relative negative`，并保存来源片段、实验条件、检测限和证据置信度的统一开放资源。这个空白目前是文献版图推断，还需要系统检索来排除遗漏。

## 已得到的认识

- Raccuglia 等证明实验室笔记中的失败合成记录具有信息价值，但只覆盖一个材料合成体系。
- Mervin 等早在 2015 年已大规模使用推定阴性生物活性数据；“使用阴性数据”本身不新。
- CARA 表明活性标签与 assay、测量类型、条件和数据源绑定，支持采用观察级而非分子级标签。
- DUD-E 偏差研究说明人工 decoy 不能自动等同于实验测得的阴性样本。
- InertDB 和 ECBD 是最直接的重叠工作：前者面向生物惰性小分子，后者保存筛选流程中的阳性和阴性结果。
- 小分子数据的 coverage bias 说明问题不只是不平衡，还包括化学空间与实验选择机制的覆盖不足。

## 还不能声称的内容

- 不能声称所有分子科学领域都存在同等程度的阴性数据缺失。
- 不能把“数据库里没有标签”解释为“实验阴性”；未测试与阴性必须分开。
- 不能仅凭论文偏好报告成功结果，就估计阴性证据的实际遗漏比例。
- 不能声称统一数据模式一定优于领域专用模式。

## 下一步判定实验

选择四个差异较大的领域做资源地图：生物活性筛选、有机合成、材料合成、分子性质测量。每个领域至少检查公开数据库、论文正文、补充信息和实验室/HTE 数据四种来源，记录阴性定义、上下文字段和可访问性。若已有资源完整覆盖至少三个领域且具有统一证据模型，本主张应降级；若各领域均存在互不兼容的局部资源，则“统一证据层”仍有成立空间。
