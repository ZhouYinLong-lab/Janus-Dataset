# 明确阴性记录的选择性自动抽取：方向核查

核查日期：2026-10-18。范围：阴性证据挖掘主课题中的一个具体方向；不评价数值删失、下游模型收益或通用基准建设。本文是文献与公开资源的核查，没有运行模型。来源、访问状态、阅读深度及文件哈希见[来源索引](来源索引.md)；公开标注包的静态检查见[本地证据核查](本地证据核查.md)。

## 1. 判断：候补，不能把现成模块组合直接当新研究

**最终评级：候补。** 最小候选是“单一酶家族文献中，明确命名的酶／变体—底物—指定产物阴性观察的选择性抽取”。普通编码模型起步可信，但当前直接可用资源不足以验证这种完整阴性记录，方法新意也尚未证实。可以做封顶验证；现在不应把它升级成主线研究方向，更不宜承诺跨领域完整实验恢复。

值得验证的具体问题是：**在同一局部文字同时出现阳性转化与“未形成指定产物”的情况下，能否自动绑定正确变体、底物和指定产物，而不错误生成“整个酶—底物不反应”的标签？** 输入中的实体也要自动定位，无法判清则弃答。这个语义区别有公开实例如E03的PMID 19670200，且会改变科学标签；相比笼统补充assay-context，它更具体。但“有这样一种错误可能”仍不等于已证明现有抽取器普遍做错，本轮没有模型运行证据来确立这一研究缺口。

支持技术可行性的证据链很具体：负结果句分类早有廉价实现（E01）；带证据的结果推断也已有专用编码模型实现（E05）；酶领域已有实体、ID、转换关系的专用流水线（E03）。因此单卡起步有技术依据。反面证据同样明确：酶领域的精确ID归一化大幅拖低完整流程成绩（E03）；高分候选的人工作品不能等同自动性能（E02）；复杂多元关系在金标准实体下仍很难（E04）。这些事实支持有界排查，不足以证明“本文提出了前人尚未处理且有价值的新方法问题”。

**单独“加一个弃答阈值和引用”没有方法新颖性。** E02已做置信排序，E05已输出证据，E07已建立风险—覆盖率评价。方向要成立，新增结果必须是某个明确科学对象上、记录级正确率与实际恢复量的可重复改善。如果规则已经做到同样效果，应交付工程工具并结束方法研究。

主线已报告CensorADMET的实际公开数据，进一步排除了“补不等号／generic assay-context”作为本分支贡献的理由。本分支没有独立复查CensorADMET，也不把它计入七项原始来源；这是接收的主线约束。

收束时主线又提供2024 overlapping_assays、2025 MatchedPairs、2026 ChEMBL_MTL先例。本分支接受这些为整合约束，不把“保留上下文／建立配对”列为新增贡献，也不冒充独立阅读过这三项。

**已知方法迁移与实际新增证据的划分：** 可复用的是E01/E03/E05/E06的抽取组件与E07的弃答评价；本轮新增的是E03公开标注包、E05公开CSV、E02公开数据的可用性和语义审计。**新增分子实验阴性记录为0，新增自动抽取性能结果为0，已确立独立方法gap为0。** 两个定向阅读的EnzChemRED实例来自已发布语料，不能写成这轮挖掘发现。最小任务是一个可证伪候选，而不是已经发现的新方法机会。主表的机器可读版本见[evidence.csv](evidence.csv)。

## 2. 先固定科学对象，防止换标签

建议首轮只处理一个已有文献积累的酶家族，具体家族由主课题样本框决定，本核查不凭空指定。输入为可取得的英文正文文本及摘要；首轮输出限定在一个句子及相邻两句内能够直接定位、且指向同一实验观察的结果。图像、复杂表格及跨段指代可弃答，但在全文分母中保留。

最小任务再收窄为：输入一个自动取得的局部段落；自动输出`(原文明确命名的酶/变体, 底物, 指定产物, tested_nonconversion, 证据span)`或弃答。产物未说明、只有代词而不能局部解析、只是缺少某辅因子、或仅无统计显著差异的段落都不强行输出。初期不自动恢复所有温度／pH，不从通用上下文信息增加新颖性主张；完整标准化版本再额外要求实体ID通过。

| 原文状态 | 本方向的处理 |
| --- | --- |
| 明确报告某酶／变体针对某底物进行了实验，在该条件下未检出活性或指定产物 | 可作为目标标签；保留作者措辞、检测方法和条件可得性，绝不扩大成所有条件下无活性 |
| 比较试验报告“无统计显著差异” | 单列；不转成“零效应”或“无酶活”。E05属于这一类 |
| 未测试、未提及、无关系标签、数据库未收录 | 非目标阴性；用于训练辨别时须有单独的“未报告／非目标”标签 |
| 无结合、无表达、结构不接触、未改变构象、负调控／抑制 | 不自动等同无催化；具体终点不同。抑制本身往往是一个实测效应 |
| 仅无某个立体异构产物，但有另一个产物 | 是指定转化的阴性，不能标成酶—底物整体不反应；E03的PMID 19670200就是这种情形 |
| 作者推测不会反应，或“不能排除”、引述他人结果 | 单列推测／背景／归属不明，不能作为本文实验记录 |

最小记录应包括：论文ID、原文中的酶及变体身份、底物／指定产物或终点、明确实测阴性类型、实验归属、证据原文与字符位置、可获得的实验方法／条件及其缺失标记。原文没有数值条件时应保留“未报告”，不能补写；如果连实验对象或终点都不确定，则弃答。

区分两个产品层级：源内身份可辨的记录可以进入证据账本；可用于酶—底物配对的数据还必须通过确切蛋白身份和化学实体对应。**源内酶名称识别正确但UniProt不确定，不得混入“完整标准化记录正确率”。** 首轮分别报告两层成功率，主张必须预先说明属于哪一层；不能在看到分数后降级口径。

### CARE的领域偏移和资源限制

CARE的主体是人体临床试验和病例报告，首轮领域对象、对照机制、测量单位、证据结构都与酶催化不同。将Population映射为酶、Treatment映射为底物只能帮助设计schema，不能继承临床模型权重的性能或把显著性语言直接变成无催化。论文跨领域检查仅各10篇计算机与材料摘要的标注可表达性；没有酶领域训练／测试，也没有跨域自动抽取性能。

标注成本不能省略：两位有科学阅读经验的标注者经历三轮pilot与六轮正式标注；Table 4关系严格一致性F1为0.4209，宽松为0.7414。两者差距提示完整记录的匹配与标注准则本身很难。不能只引用宽松一致性说金标准已接近无歧义。

论文Appendix F报告生成模型微调用两张48GB RTX A6000，每次9–17小时。它**不是消费级单卡复现的直接证据**。本次已取得17页正式全文，但论文所给 `github.com/allenai/CARE` 网页及main/master README访问失败（网页404，GitHub API另有403限流）；未取得标注包，不能声称检查过其无效结果的类别数量或许可。详见来源索引。

## 4. 可复用资源已经到哪一步

EnzChemRED公开[Zenodo标注包](https://doi.org/10.5281/zenodo.11067998)是可用起点，许可为CC BY 4.0。本轮下载的固定版本包含1,210个BioC XML。作者[GitHub入口](https://github.com/ncbi-nlp/EnzChemRED)主要是README，实际流水线指向[NCBI tar包](https://ftp.ncbi.nlm.nih.gov/pub/lu/EnzChemRED/EnzChemRED_pipeline.tar)，并依赖AIONER、BioREx、MTCR和UniProt对应；本轮没有下载或运行该整套流水线。不能把“GitHub可见”写成环境已复现。其阳性关系和实体标注可借用，20个阴性化学关系不能当作足够的酶阴性训练集。

由此要诚实地区分：**现在拿得到资源并可开始学习性复现的是化学对关系抽取、否定scope检测，以及给定ICO的临床证据分类；不是完整的酶—变体—底物—指定产物阴性抽取。** 旧环境能否直接运行仍未验证。后者需要新增领域标注，尤其在20个阴性化学对之外补齐酶／变体归属与“局部产物阴性≠整体不催化”的错误类型。新增这批标注可以是一项工作，但不能仅凭前人未发布这种标签就推导它有方法研究价值。

Evidence Inference的[作者仓库](https://github.com/jayded/evidence-inference)可访问，实际下载标注CSV核得24,686行、12,616个已标注prompt、3,346篇，与2.0论文吻合。CSV有1.1版遗留说明，但数据规模不能因此误判为只取到1.0。11,129条“无显著差异”是标注行数，含多位标注者／多段证据，不能当独立记录数；924行offset为-1，回溯需处理缺失。它适合作证据定位和结果分类的公开起步任务，不可直接当酶实测无转化语料。

Negatome的[人工子集](https://mips.helmholtz-muenchen.de/proj/ppi/negatome/manual.txt)本轮下载核得2,171行，每行有蛋白ID、PMID和实验方法。它不是带原文跨度、条件和弃答标签的现成训练集；旧Excerbt定制代码可直接复用到何种程度未核实，最终数据库也不等于原始候选及错误标签全集。E01的444句原始训练集与代码，本轮未找到可核验下载，不能承诺复现其原始切分。

NegBERT[作者代码](https://github.com/adityak6798/Transformers-For-Negation-and-Speculation)和数据入口可访问；本轮读了README，未审查或执行notebook。E07的[作者代码](https://github.com/geifmany/selective_deep_learning)可访问，静态读了`risk_control.py`，能确认它以置信分和0/1残差计算阈值及二项风险上界。它仍须移植到记录错误标签和按论文隔离的校准过程，不能直接对token置信度作“整条记录95%可靠”的保证。

## 5. 单消费GPU是否能起步，代价在哪里

**能起步，前提是短文本、复用已训练编码器、模块顺序执行，并接受实体不确定时弃答。** E01的基线不需GPU；E06给了110M模型在免费GPU训练的直接先例；E03已有酶领域小编码器模块。12–16GB消费GPU上微调一个base编码器、短窗口、小batch与梯度累积，是合理工程估计，尚未在本机验证；不承诺显存、速度或训练时长。多模型不需要同时常驻，更不需要重新进行生物医学预训练。

真正不确定的是人工与适配成本：酶变体、同名异物、底物泛称、产物特异性、实验归属和检测终点需要领域标注。E03标注者有策展经验且可查询外部资源；E05先由医生建立ICO；这些劳动不在推理GPU费用里。E02即使高分排序后仍靠人工补方法和物种，说明把“省阅读时间”升级为“自动完整记录”会增加成本。

建议成本账至少分四项：一次性标签／实体字典建设，编码器训练与推理，全文取得／解析，运行后的盲审。按篇和按自动正确记录同时记账；不能仅报GPU每篇费用。下文的120专家小时是拟设预算上限，不是文献给出的工时估计。若只能靠每条人工读完后修正，路线就应更名为辅助策展；不能继续报告无人生产性能。

## 6. 最小可证伪主张及验证边界

以下是候补方向升为“推进”的必要证据方案，本轮未执行，也不因写出方案就认为研究gap已经确立。

### 可检验主张

在预先固定的一个酶家族、可取得全文的连续论文样本上，**不调用前沿通用模型，不给测试集金标准实体或人工挑选候选，冻结的编码模型＋记录校验＋弃答流程，能在标准化完整记录精确率点估计≥95%时，找回至少25%的“局部文字可恢复明确阴性”，且自动正确记录数达到同等标注预算规则基线的至少1.5倍。** 输出必须带足以支撑该记录的证据，未修正的原始输出进入统计。

这些数值是建议事先锁定的继续／放弃阈值，不是本次结果，也不是根据前人分数推算。若源内证据记录通过、确切ID层失败，只能声称前一层成立；标准化数据生产方向不算通过。

### 一个封顶方案

1. **先做资源和研究问题闸门。** 取12篇非按“容易负例”挑选的论文，最多20专家小时，检查能否稳定区分“实测无转化、未测试、其他终点、背景／推测”，并测量局部文字可恢复比例与身份可解析率。另在已有公开段落上比较现成规则／EnzChemRED式流程是否真的发生“指定产物阴性误作整体无催化”与变体错配；没有这种可重复的失败，就不继续讲这个gap。这一步仅建标签和估计可行性，人工找到若干条不能作为模型性能。
2. **通过后冻结100篇的样本框。** 20篇开发、20篇校准、60篇盲测，按论文／重复研究分组隔离，固定来源与时间边界；不从系统命中的句子反向挑测试论文。至少一部分来自开发期未覆盖的作者或期刊来源，以观察文风迁移，但单独报告，不能声称校准保证跨域成立。训练量不足时，开发池扩充必须占用总标注预算并发生在盲测前。
3. **比较四个同输入流程。** A：关键词＋句法／实体约束规则；B：复用编码器的实体／关系模型无弃答；C：B按置信分弃答；D：B加实测归属、指定终点、变体与ID唯一性门控后弃答。各阈值只看校准集。比较相同目标精度下的正确输出数，区分“编码模型的增量”与“单纯少答的增量”。
4. **保留整个分母。** 金标准应独立通读盲测论文可取得的正文／补充材料，登记全部明确阴性，包括系统不支持的表格、图与长距离证据；文本、表格、图分别标注位置。否则无法知道系统自选的简单部分究竟有多大。达不到这一阅读预算时，只能改称候选精度实验，不能声称全文恢复率。
5. **预算封顶。** 累计120专家小时、最多两轮开发修订；先记录每篇与每记录实际工时，再决定是否做完整盲测。该预算是否足够未知，若不足以建立可信分母就不进入“通过”判定。模型开发可另计工程工时，但不得把工程人员的逐条科学判读藏入自动生产。

### 评价单位必须同时给出

| 指标 | 分子／分母与限制 |
| --- | --- |
| 完整自动记录精确率 | 全字段、实验归属、ID、指定阴性终点及其证据均正确的未修正输出／全部接受输出；缺ID或错误条件绑定算失败 |
| 源内证据记录精确率 | 不要求外部标准ID、但源内身份与证据齐全的正确输出／全部该层接受输出；单独报，不与上行拼接 |
| 局部文字阴性召回 | 正确恢复的局部文字阴性／盲测集中全部符合预设局部范围的实测阴性；不能只在检索命中内算 |
| 全文恢复率 | 自动正确完整记录／同批论文中所有已发表、可取得的目标阴性；表图及长距离弃答留在分母 |
| 接受率／弃答率 | 以冻结流程产生的候选为分母；检索漏检另计。候选接受率不是全文召回，也不是E07意义下覆盖总体输入的唯一方式 |
| 产量与回溯通过率 | 每100篇的自动正确记录数；其中原文位置可打开且足以支撑对象、终点与结论的比例。仅有引用URL不算支持成立 |

同时画记录级风险—接受率曲线，给置信区间并按论文聚类；报告失败解析、空输出、未知ID、缺失条件及全部弃答。可列出来源级差异，避免一篇有几十条记录主导分数。

若盲测不足50条接受输出，或来自不足20篇，视为证据不足而非证明95%。即使达到这些数量，95%点估计也不等于可靠性下界95%；不得升级成部署保证。举例：若真有59个独立单位且零错误，单侧95%二项下界才约95%，同篇多条不能当59次独立试验。阈值选择、开发与最终置信区间还须避免重复使用同一标签。

## 7. 何时放弃，何时只留候补

| 观察到的事实 | 决策 |
| --- | --- |
| 现成专用模型／规则在目标困难类型上已满足精度与产量，新增只是加引用、字段或弃答阈值 | 淘汰作为独立研究方向；只保留学习性复现／工程组合 |
| 首轮标签主要是未测试／背景／无结合，或指定产物阴性被系统普遍误作整体不催化 | 淘汰当前任务定义，先修科学对象；不能以放宽阴性语义挽救产量 |
| 局部文字可恢复阴性不到全部目标的10%，或多数连酶／变体和底物都不能确定 | 本方向降为候补；主课题优先级应转向其他获取方式，本分支不展开 |
| 准确率达标但需要弃答到局部召回<25%，或产量不足评价下限 | 候补／终止当前规模的验证；不宣称便宜且可用。不得只展示top-20 |
| 与强规则基线相比正确记录产量未达1.5倍，或改进在锁定盲测中消失 | 淘汰“值得做方法研究”的主张；规则工具可保留作工程产物 |
| 源内记录可用但确切蛋白／化学ID持续失败 | 只保留“证据索引”候补；淘汰已经自动产出模型可用配对的说法 |
| 专家预算耗尽仍不能形成可靠金标准／分母，或每次新文风都须逐条人工修正 | 停止无人生产方向；如有需求另立人工辅助策展任务，不冒充本方向成功 |
| 未修正的自动输出达到锁定精度、恢复量和基线增量，且工时可摊销 | 推进下一批同领域外测；跨家族、跨版式及下游用途仍须另验 |

最终排序：**酶／变体—底物—指定产物阴性的选择性抽取——候补，可做封顶验证，尚无充分证据升为研究主线；跨域n-ary完整实验抽取——本轮不推进；现有数据上的scope／关系分类——可做学习性复现，但不作为新研究gap；把否定检测高分、强模型或人工读出若干条当作自动生产性能——淘汰。** 当前缺少的是现有系统在具体科学标签上的可重复失败及低成本改善证据，不能用“复杂关系很难”替代它。
