# 小模型三组训练与本地评价（2026-10-28）

## 训练

基础模型 Qwen3-0.6B-Base，LoRA r=8/alpha=16，q_proj/v_proj，100 updates，seq 512，batch 1×4，GPU RTX 5070 Ti。

| 组 | 训练/验证记录 | 验证 loss | 输入 token |
|---|---:|---:|---:|
| positive_only | 116 / 32 | 2.388 | 204,800 |
| domain_control | 116 / 32 | 2.391 | 204,800 |
| balanced_negative | 116 / 32 | 2.457 | 204,800 |

三组均正常完成并保存 adapter/checkpoint。loss 只用于排查训练，不作为任务增益指标。

## 本地评价

- 312 个任务（78 题 × 4 模型：base + 三个 adapter），GPU 本地推理，0 API 请求。
- 结果：**312/312 `invalid_response (json_or_citation_contract)`**。
- 抽查输出：模型把输入问题原样重复并拼接，没有给出要求的 `answer / citations / uncertainty` JSON。

## 结论

- 训练流程跑通：数据、适配器、GPU、复用都可执行。
- 0.6B 基座 + 100 步继续训练**不能**遵循引用 JSON 合约；因此本轮没有形成可用的小模型效用对照。
- 这是格式遵循失败，不是“阴性训练无效”的证据；不能把 312 个失败当作效用为零。

## 下一步选项

1. 增加格式适配（在相同证据上做 JSON 输出 SFT），再跑同一评价。
2. 改用模型能完成的任务形式（如强制选择/排序），与之前 0.6B 试跑一致。
3. 换更大基座重跑。
