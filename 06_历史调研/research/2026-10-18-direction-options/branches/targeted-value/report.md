# 定向恢复有信息量的实测失败：建议做什么，否定什么

2026-10-18。有界独立核查；6项关键一手工作，重点为两篇2024年HTS研究。全文及数据入口见[证据索引](证据索引.md)，下载指纹见[来源清单](来源清单.csv)。没有运行训练、模型推理或原作者脚本。

**对targeted-negative fixed-budget的直接回答：本轮没有找到“定向恢复/新增失败，在相同实际标签获取预算下胜过便宜随机负例”的直接正证据。最接近的等量实测阴性选择对照是T01欠采样，未胜随机。T01主动筛选、T02/T03复核、T04酶主动学习均不能替代这个缺口。**这是截至本轮所读材料的判断，不是断言所有文献都没有。

交付入口：[六项机器可读证据](evidence.csv)、[资源可用性与优先级](resources.md)。本文后半部分是拟议研究设计，不是已完成复现。

## 决策

**支持一个小规模、可失败的研究：在明确酶家族的底物筛选任务中，比较“定向恢复的已测试失败”与随机推定负例、随机实测负例的边际用途，并把化学距离和获取费用纳入结果。暂不支持直接以“大规模挖文献阴性改善模型”立项。**

具体优先级：先使用现成酶面板建立受控的价值曲线，主任务限定为“已知酶、未见底物的筛选排序”。确有收益后，只恢复同一任务范围内、现有资源缺失的文献观察。HTS初筛—复筛面板适合作为质量与预算对照，但不建议成为本项目的主创新。

**普通RF足够承担这项复现，不需要研发新模型。首选酯酶实测底物面板，腈水解酶作小型复核；首要区分的是“与已知底物相近的已测试未命中”与“相近但未测试/未标注”和“远距离随机推定负例”。**若原任务已经有大量合格实测阴性，优先检查冗余与局部缺口，不继续泛泛扩负类。主线关于CARA的任务差异提醒与此一致；本支路未重复核读CARA，也不以所有任务均缺阴性为前提。

务必区分三种交付：公开HTS标签再利用、已公开酶面板的模拟隐藏/恢复、历史论文中现有结构化资源未覆盖记录的新增恢复。前两者可验证价值，均不能充当第三者的数据新增量；本文不承诺新意。

主线另提供[2026年ACH/target/MTL研究](https://doi.org/10.1021/acs.jcim.6c01018)：422个held-out assays、24个targets，较干净ACH数量较少、没有一致meaningful增益、RF优于GNN，但并非阴性消融。本支路未独立核读，**仅作为主线提供的边界提醒，不列入六项独立核查证据，也不把“更干净”预设为会涨分。**

这不是要求实测失败必须“不可替代”。若它在相同效果下节省获取成本，或在相同预算下减少一次筛选中的无效候选，即有实际价值。相反，只有相对无负例模型上涨、相对随机负例不上涨，不足以支持扩大恢复规模。

## 1. 新证据改变了什么

### T01：重要阴性确实存在，但定向保留未必胜过随机

[Hesse等，2024，数据估值](https://doi.org/10.1021/acs.jcim.4c01547)包含三个不同实验，不能混为一条证明：

| 实验 | 对照及结果 | 对本问题的证据力度 |
| --- | --- | --- |
| 主动筛选 | 每批1.5%；在一个集合优化后，余下24个集合上，MVS-A加GPR优于greedy | 支持等批量下选样策略有用；新增样本包括正负，训练用初筛标签，不能隔离新增阴性的贡献 |
| 初筛命中复核排序 | 25个初筛—复筛集合；复筛结果用于评价 | 支持优先核实疑似假阳性；不是新增负例训练实验 |
| 阴性欠采样 | 同步每次移除原训练集5%的阴性，在同一验证集评价；删除高重要性阴性损害预测，但删除低重要性阴性没有胜过随机删除 | 是最直接的反面结果：能辨认重要阴性，不等于能更有效选取阴性；不是严格独立最终测试的证据 |

欠采样主图集中展示10个aging集合中基础precision超过10%的4个，其余6个基础预测较差；保留MolData既有划分，但Methods明确写LGBM在**validation set**上评价。因此是同验证集的策略比较，不能称严格独立最终test的验证。不能将这项结果包装为跨25个集合的负例选择成功。正文把主动筛选收益归因于关键阴性和多样性，是解释，不是单独的负类消融。

**研究含义：便宜随机实测阴性是必须击败或节省成本的对照；只证明删除某批失败会掉分，价值主张仍不完整。**

### T02：优先核实“失败”早已有成熟的近邻先例

[Boldini等，2024，MVS-A](https://doi.org/10.1021/acscentsci.3c01517)使用17个公开HTS配对和3个工业集合，排序只用初筛、评价参照复筛。CHT案例中，5个最终真命中均进前20；初筛假阴性CHT4在inactive复核排序中居首。工业集合上，初筛读数排序在部分真命中指标更好。

所以，“用模型找值得复核的初筛阴性”“识别对模型不寻常的样本”“减少复筛浪费”都不能声称空白。该研究的假阳性还合并了复筛inactive与inconclusive，不能原样当作严格确认的阴性训练金标准。它未比较“等量新增确认阴性”与“等量随机推定负例”的下游增益。

### T03：157个结果是救回阳性，不是获得157个可靠阴性

[Swamidass等，经济复核框架](https://doi.org/10.1177/1087057110372803)正式发表于**2010年**；2011年是PMC作者稿开放时间。它预测追加462个化合物的复核收益，最终找到157个额外活性物。追加批次还包含213个此前物料不可得的较强命中，不能解释成随机抽取462个明确初筛阴性后的普遍纠错率。

该工作证明按边际发现成本决定追加复核和停止有实用先例；没有等预算随机复核臂，也没有新增阴性训练比较。它支持“优先核实看起来失败的记录”，不能支持“这些记录应更坚定标为负类”。

### T04：酶文献恢复加主动选样也不是新概念

[Pertusi等，2017](https://doi.org/10.1016/j.ymben.2017.09.016)是旧表L39，本轮取得全文，属于阅读升级。作者已手工从原始文献寻找数据库缺失的实测非底物，并用SVM信息密度选择实验。MenD、AAEH的同测试学习曲线优于随机选样，Car、HAPMO没有显著优势；不是四酶普遍获益。

关键区别：新增实验最初8个化合物全部表现为底物，随后验证3个也为底物。因此，实验支持定向选样和纠正特征混淆，**没有证明新获得的失败比随机负例更有效**。与纯选“最远分子”相比，它同时考虑不确定性及候选空间代表性。

### T05—T06：新面板值得查，但旧面板更适合立即建立公平对照

[CATNIP，Nature 2025](https://doi.org/10.1038/s41586-025-09519-5)报告314酶×111底物、三重复筛选；然而BioCatSet1建模主要整合成功反应，公开`reaction_table.csv`也不是完整正负矩阵。当前文件还有版本/重复行需要核对。不能据其规模直接宣称新获得数万条可靠非底物。

[Goldman等，2022](https://doi.org/10.1371/journal.pcbi.1009853)是旧文，仅复用其开放面板。其[数据仓库](https://github.com/samgoldman97/enzyme-datasets)已有酯酶、腈水解酶、卤化酶等可下载CSV和解析脚本。GT说明明确含未测试编码为0；卤化酶二值0含低转化，不能称绝对非底物。现成资源须先按来源审核，但比从零挖散落语句更适合辨认价值。

## 2. 哪些任务和化学距离值得获取

以下是本轮证据支持下的**研究优先级判断**，不是已被文献量化的效应排名。没有找到足以规定统一Tanimoto阈值、保证近邻阴性优于随机阴性的直接研究。

| 任务/位置 | 获取判断 | 具体理由和限制 |
| --- | --- | --- |
| 已知酶，挑选未见候选底物；已知底物周围有相似但失败的分子 | **最高优先级** | 能检验模型是否把相似性当作可转化性；目标是减少top-k误选。近邻失败仍可能冗余或有误，不预设必胜 |
| 同家族中，模型判断分歧大且有多个候选分子受影响的区域 | **值得作为第二种定向策略** | 比无限追逐孤立异常更有覆盖机会；选择时只能使用已获取的训练信息 |
| 极远、缺少相关反应基团的分子 | **不优先高成本恢复** | 对局部底物筛选可能容易排除；先用随机/化学规则负例作便宜对照。远距离部署任务另计，不能说永远没用 |
| 初筛inactive但模型预测活性高 | **优先复核标签，不能直接加强负标签** | T02、T03表明可能救回阳性；复核价值和负例训练价值不同 |
| 初筛active、复筛失败或不确定 | **可作HTS质量任务，不作酶非底物替身** | 假阳性排序已有强先例；需要区分复筛inactive、inconclusive和缺失 |
| 已有大量目标内实测阴性、还想再换一种“更真实”负类 | **低优先级** | T01欠采样没有胜过随机；旧InertDB/PADIF/SNA也已限制“实测来源必胜”的论断，本轮不把它们算新发现 |
| 新蛋白家族和新化学骨架同时外推 | **不作首次小研究目标** | 多个变化混在一起，很难把结果解释成失败记录的价值 |

距离应相对于**选择时已知的目标酶底物**计算，而不是相对于测试集或恢复完成后的全部阳性。先用训练候选内距离分位数分近、中、远，保留反应基团和骨架信息；不从文献借一个看似精确的通用阈值。每个距离层都用同一个独立测试子集比较策略。

## 3. 标签必须分开

| 记录类型 | 能提供什么监督 | 本研究处理 |
| --- | --- | --- |
| 明确进行转化测试、报告未观察到产物/活性 | 测试范围内的实测失败 | 主恢复对象；保留原始判定与来源，不泛化为任何情况下绝不反应 |
| 有转化但低于作者二值阈值 | 任务阈值下的低活性 | 可研究，但单列来源；不用“非底物”偷换 |
| inhibitor | 抑制某过程/酶的证据 | 不自动推出不能被该酶转化；不并入非底物主训练臂 |
| 数据库未收录、未测组合 | 未标注 | 可以构造便宜推定负例对照，不能改称实测 |
| 计算decoy、错误姿势或跨目标拼接 | 计算/构造负类 | 独立对照；不算新实验失败 |
| 复筛inactive / inconclusive / 未复筛 | 分别为该复筛未活跃 / 无定论 / 缺失 | 分别保存；二值预处理文件不够时回溯原始AID |

本支路只划定标签来源和选样问题，不展开删失数值或条件模型。

## 4. 可执行的小研究：先回答价值，再决定恢复规模

### 第一阶段：现成面板上的受控价值审计

**主问题：固定已知酶和训练阳性后，恢复哪类失败能减少未见底物筛选中的误选；收益来自真实标签、化学位置，还是仅来自增加数量？**

建议以酯酶为主、腈水解酶作小型复核。已下载的版本分别为14,016和684配对。前者3,076阳性，后者仅85阳性；全表具有至少5阳性且16阴性的酶分别123/146与5/18（只是描述统计，非训练划分后的资格）。因此不承诺两个家族都会给出有统计把握的独立验证。若某距离层或测试折没有足够正负，不靠重切种子制造显著性。卤化酶NaBr可作低活性负类的附加检查，不能混入严格非底物主结论。

1. 先审核原始补充表中空白/未测与0的区别；二值脚本中`>0 else 0`会把缺失也落入0的风险必须排除。审核失败的面板退出。记录与现有数据库、Goldman等资源的重叠，现成标签只是研究载体，不称新增恢复成果。
2. 固定一个“已知酶、底物整组留出”的共同测试方案；同一底物的各酶配对不能跨入训练。再作骨架分组检查。所有策略使用相同测试记录、模型、特征、**种子训练阳性**、基础阴性、随机种子和调参预算。种子阳性只是训练区内预先公开的一部分；剩余候选的真实标签先隐藏，不能先公开所有阳性再假装剩余池含未知正负。
3. 每个面板设新增负例预算32、64、128条；候选不足则预先缩为8、16、32。采用下面的来源×选择对照，不用规模差异冒充价值。

| 对照臂 | 内容 | 回答的问题 |
| --- | --- | --- |
| B0 | 不新增负例 | 是否仅因原来负类不足 |
| B1 | 同样数量、同候选化学范围内随机抽未标注配对并暂作负类 | 便宜随机推定负例是否已经足够 |
| B1-near | 按与种子底物的相近程度，从未标注池选同样数量并暂作负类 | 便宜的相近推定负例是否已足够；其隐含假阴性另由金标准事后统计 |
| B2 | 随机抽取已测试失败 | 实测来源相对随机推定的价值 |
| B3 | 从已测试失败中选择近邻且去冗余的记录 | 定向位置相对随机实测的价值 |
| B4 | 从已测试失败中随机抽取，但匹配B3的距离层、骨架覆盖和酶覆盖 | 是否仅是空间分布变化，而非更细的选择方法有效 |

B2—B4是**已经知道失败标签时的事后价值上限实验**，不是等实验预算的主动获取证明。须固定阳性后做等负例数比较，适合回答“这类失败用不用得上”。选择过程不得查看测试标签，也不得以测试损失计算样本重要性。

主指标预先定为每酶top-5候选中的实测失败数，辅以命中数和整体AP；已测低活性另报。测试保留实际正负组成。对近、中、远距离分层报告，使用配对差和区间；不能只挑最有利的距离层。

**RF最小实现规格（拟议，未运行）：**每个已知酶一个RF，以分子ECFP4为特征，固定500棵树和统一类别权重，不做逐臂调参。先冻结25%底物测试集合及5个共同划分种子；训练区每酶预先给定少量阳性和共同基础负例，剩余作为隐藏候选。负例预算可取每酶4、8、16条；达不到训练样本要求的酶按预定训练区标准排除，并报告保留覆盖，不能查看测试成绩才排除。腈水解酶只有38底物，若样本不足，保留为描述性复核而不硬凑跨家族显著性。

此处全家族预算32/64/128与每酶预算4/8/16是两种可选预算单位，实施时**预先选一种**；建议首轮选每酶预算，报告合计配对数，不在看过结果后换单位。每臂独立初始化相同RF，测试集、阳性身份、正负数、基础负类和特征完全相同；不得一臂额外获得蛋白预训练表示或更多阳性。

B1-near与B3还应作距离匹配比较；测量/推定标签与选择距离至少要有这一个交叉对照。若只比较近邻实测与远距离随机，所得只是整套获取方案的效应，不能归因于“实测”二字。伪负例在实验中由已测面板遮蔽标签模拟，必须明确这是模拟未标注，不是真正未测试的实验事实。

“等负例数”意味着各臂赋予同样数量的负标签，**不意味着等标签成本**：B2—B4的真阴性池使用事后标签资格，存在标签oracle；B1/B1-near的推定0无需实验复核。因而第一阶段用于估计内容价值上限及每条标签效果，第二阶段才估计单位核查预算的实际效果。若要检验等实验查询预算，就在混合正负候选中每次查询4/8/16个真实结果，所有查询及正例都计费、如实加入；这将成为另一项选样实验，不能和固定阳性的负类替换混写。

**关键解释规则：**B3若胜B1却不胜B2，支持补实测来源，不支持定向选择；B3若只胜B2、不胜B4，支持距离/覆盖优先级，不支持复杂数据估值方法。B3即使能被更便宜方法追平，也不等于数据毫无价值，要比较达到相同指标所需成本。

### 第二阶段：只有第一阶段成立，才做小批文献恢复

限两个家族、最多20篇文章/补充材料、总核查6人时或100个候选记录，以先到者为止。先去掉现有开放面板的已收录内容，目标是验证新增、可复用的失败记录是否值得找。候选定位可用文本规则或已有工具，不把本次人工读文当作抽取器性能。

在不知道候选完整标签前，按“已知底物近邻且去冗余”与“同家族合格候选随机”两种策略安排核查。两臂使用相同文章/表格可访问范围与难度约束，正例、歧义、重复和无法对齐也计入预算。到达每个预定的30/60/100次核查和2/4/6人时节点比较；若共用一条已审核记录，审核费用在两条独立策略轨迹中各记一次，不能让后到策略免费获益。

同一个冻结测试集上报告每预算所得的最终任务收益、可靠且新增的失败数及每条成本。此阶段允许正例产量随策略不同，因为这是实际获取效果；另在第一阶段的等负例数实验中隔离负类贡献。**不能先从金标准挑出100条真阴性，再宣称只花100条标注预算。**

现成面板只能模拟记录被隐藏后的价值，不能证明文献中存在足量、机器可恢复、数据库未覆盖的同类失败。第二阶段正是为这个跨越付账，而不是重复一次主动学习基准。

## 5. 新意还剩多少

| 拟议主张 | 判断 |
| --- | --- |
| 第一次恢复文献非底物训练模型 | **否定**：T04已手工恢复；旧EPP/Goldman及其他模型也形成不同程度先例 |
| 第一次用主动学习为酶选有信息的实验 | **否定**：T04直接覆盖 |
| 第一次识别重要实测阴性、用于欠采样 | **否定**：T01直接覆盖，且未胜随机的结果尤其不能略去 |
| 第一次优先复核HTS阴性或按经济价值停止 | **否定**：T02和T03覆盖 |
| 哪类可恢复的失败，在相同测试和预算下比随机实测/推定负例更划算 | **保留为具体研究问题**：本轮6项中未见把文献获取、空间匹配、标签预算和下游任务同时接通的直接证据；这不是穷尽检索后的首创证明 |
| 明确圈出“值得恢复”和“随机足够”的范围 | **可成为结果**：不需要证明实测记录不可替代，但须比“加了有效”更有辨识力 |

宽泛概念的新意已被消灭，问题导向的小研究尚未被这些先例消灭。若贡献最终只剩复现MVS-A或SimAL，没有新来源的缺口与获取成本证据，应按复现/工程评价交付，不能包装成新的文献阴性方法。

## 6. 明确停止条件

以下是本报告建议的项目门槛，**不是文献确立的通用标准**。

| 关口 | 停止/转向规则 |
| --- | --- |
| 来源资格 | 无法排除未测/缺失被编码为0，或无法把记录对应到实际测试对象：剔除该面板；两个家族都不合格则停止该小研究 |
| 任务改善 | 预算上限处，两个家族均未达到平均每酶top-5少一次失败，且AP绝对改善不足0.02：不扩大文献恢复。区间宽而无法判断时，结论为在既定资源下不支持扩大，不无限追加 |
| 目标明确性 | 只胜随机推定、不胜随机实测：转为可靠标签来源项目；只胜未匹配随机、不胜距离匹配随机：采用简单距离/覆盖规则，停止复杂选样研发 |
| 可获取性 | 最多20篇/6人时/100候选后，尚不足30条“可靠、去重、现有资源未覆盖”的失败：停止此来源的规模化恢复；这只是当前流程的可行性否定 |
| 效率 | 定向臂和随机核查臂最终效果相当，定向成本没有下降；或便宜对照达到同效果且费用更低：不推广定向恢复 |
| 范围 | 收益只出现在邻近底物，不出现在远骨架：将结论限定在局部筛选，不能改写成广泛泛化成功；局部收益若足够仍可保留 |
| 事后选结果 | 只有换测试集、改变正负比例、挑一个家族/种子才获益：判为未通过，不以继续调参延长项目 |

**最终取舍：立一个两家族、有限标签与核查预算的价值审计；不立统一阴性挖掘平台；不以HTS复核排序或“阴性很重要”作为独立创新。**通过门槛后再考虑自动化恢复；未通过就交付哪些空间与来源不值得投入的负结果。
