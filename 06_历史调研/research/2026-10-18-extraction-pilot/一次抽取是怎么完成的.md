# 一次抽取是怎么完成的

这个例子取自Hu等2022年的论文，DOI：[10.3389/fmicb.2022.860014](https://doi.org/10.3389/fmicb.2022.860014)。原始PDF和完整XML都在`sources/`。目标是找回“BaBgl3A对Rd的实验结果”，而不是给BaBgl3A永久贴一个无活性标签。

## 1. 先找候选，不急着定标签

固定规则扫描到Results中的`P35464910-B0059`，这里同时讨论三种酶和两种人参皂苷。作者报告BaBgl3A能把Rb1转成一些产物，但对Rd没有活性。

这时只知道有一条可取证的定性阴性。不能把该段所有酶、底物都标阴性，也不能把“活性弱”当成没有活性。脚本只把这段交给阅读者。

## 2. 结果、方法和图注要一起读

| 要填什么 | 从哪里取得 | 这次填入什么 |
| --- | --- | --- |
| 蛋白及来源 | Results `B0023`及补充图1 | BaBgl3A，B. adolescentis ATCC15703，BAF39975.1 |
| 底物和结果 | Results `B0059` | 人参皂苷Rd；作者报告无活性 |
| 是否真正测试 | Methods `B0022`、Figure6图注`B0060` | Rd明确列入测试；TLC的A4泳道对应这个配对 |
| 温度和时间 | 人参皂苷转化Methods `B0022`及图注 | 37°C、2h |
| 酶和底物浓度 | 同一Methods | 酶终浓度0.1mg/mL；Rd 5mg/mL |
| pH | Methods说最适pH；Results `B0035`给对应值 | 通过两段连接到6.5；标明这是协议对应，不是假装同一行直接给出 |
| 缓冲液 | Methods及通用最适条件图注`B0037` | 50mM、最适pH；通用图注指向磷酸盐；保留映射依据 |
| 检测与证据位置 | Methods及Figure6 | TLC定性结果；方法也列HPLC，但未取得该阴性配对单独的HPLC定量曲线 |
| 检测限、逐次原始值、该转化反应重复数 | 所读方法、图注、补充文件 | 未明确取得，留空/未报告，不按其他图的三重复套用 |

同篇论文中BaBgl3A的最适温度是45°C。若直接把“最适条件”复制过来，就会把这里明确在37°C完成的人参皂苷实验填错。这就是为什么条件必须绑定到具体实验。

## 3. 保存两种东西

第一种是原始证据：来源文件、正文B编号、图号和泳道、作者结果表述，以及没有取得的信息。

第二种是供后续任务使用的解释：`source_reported_negative`，即作者在上述条件下报告的定性阴性。它可以作为条件性二分类候选；不是精确测得的数值0，也不是独立重做实验后确认的绝对真值。

完整行是`extracted_observations.csv`中的EX003。EX001、EX002用同样办法整理BaBgl3B对Rb1和Rd的结果。来自同一段的多个结果只有在实体、底物和图注能明确分配时才分成不同观察；同一结果在结论中再说一次不重复计数。

## 4. 遇到下面这些情况就不生成阴性

- BaBgl1A对gentiobiose：正文称无活性，表3为9.65%相对活性。把两处并列，暂缓标签。
- BaBgl3B对pNPαAraf或sophorose：表3是未定义破折号。知道它在测试面板里，仍不足以确定破折号表示什么。
- BGL-1的70受体面板：有测试名单和“大多数未命中”的总结，没有逐受体结果。不能用70减几个阳性凑出一批确定阴性。
- 核磁化学位移表里的破折号、结晶未见电子密度：测量对象不同，不当作催化无活性。
