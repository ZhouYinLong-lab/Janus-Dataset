# 阴性平衡传统模型结果

本实验比较三种等规模训练数据：阳性偏置分布、加入已有结构化阴性的平衡数据、加入正文恢复阴性的平衡数据。每次按DOI隔离测试论文，并排除训练和测试之间相同的分子—靶标—E3组合。三个固定划分的训练集分别包含72、80和80条记录，测试集分别包含24、20和20条平衡记录。

| 模型 | 训练数据 | 准确率 | 宏F1 | 阴性误报率 | AUROC |
|---|---|---:|---:|---:|---:|
| Logistic Regression | 阳性偏置 | 0.517 | 0.385 | 0.933 | 0.640 |
|  | 结构化阴性平衡 | 0.531 | 0.431 | 0.739 | **0.671** |
|  | 恢复阴性平衡 | **0.561** | **0.496** | **0.261** | 0.642 |
| ExtraTrees | 阳性偏置 | 0.500 | 0.357 | 0.967 | 0.626 |
|  | 结构化阴性平衡 | 0.531 | 0.413 | 0.906 | **0.711** |
|  | 恢复阴性平衡 | **0.542** | **0.477** | **0.400** | 0.674 |
| 小型MLP | 阳性偏置 | 0.550 | **0.507** | 0.711 | 0.569 |
|  | 结构化阴性平衡 | 0.528 | 0.387 | 0.611 | **0.627** |
|  | 恢复阴性平衡 | **0.564** | 0.503 | **0.261** | 0.612 |

相对结构化阴性平衡组，恢复阴性组在三个模型上的准确率提高1.1至3.6个百分点，宏F1提高0.064至0.116，阴性误报率下降35.0至50.6个百分点。三个模型的AUROC同时下降0.015至0.037，说明恢复阴性主要改变了固定阈值下的决策边界，没有稳定改善整体排序能力。

结果支持一个范围明确的结论：正文恢复阴性能够减少模型把真实失败实验预测为阳性的倾向。当前测试分片较小，且不同划分之间波动明显，因此该结果属于任务内局部增量。原始条件字段全部保留，但阳性池没有同等条件覆盖，本轮未把条件缺失模式输入模型。
